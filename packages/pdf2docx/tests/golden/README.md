# 黄金回归语料库

各语言的黄金 PDF 及其预期的转换快照。目录结构：

```
golden/
  en/  拉丁文本：词间距阈值、连字符、对齐用例
  zh/  简体中文：不插入空格、eastAsia 字体槽位、中英文混排
  ja/  日文：假名/汉字混排；竖排文本页面必须降级为位图
  ko/  韩文：保留真实的谚文词间空格
  ar/  阿拉伯文：P1 预期 = 页面降级为位图（无乱码文本）；P2 切换为真正的 RTL 输出
```

每个用例是一对文件：

- `<name>.pdf` — 输入文档（体积小，可安全再分发）
- `<name>.expected.json` — 断言：按顺序排列的段落文本、每段的对齐/缩进、图片数量、预期的 `warnings`

约定：

- 来自上游 pdf2docx Issue 的反面示例（空格丢失/重复 #103、RTL 反转 #73）在移植过来后应归入此处——命名为 `issue-<n>-*`。
- 保持 PDF 为生成的（参见 `tests/helpers/fixtures.ts`）或自由许可的。
- P1 以即时生成的 fixtures 交付结构；已提交的样本随着我们修复的每个回归而增长。遍历这些目录的运行器将随第一个已提交样本一起落地。
