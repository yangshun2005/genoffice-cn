# GenOffice Sheets

面向 macOS 和 Windows 的 AI 原生电子表格应用。

## 已实现的功能

- Electron 权限分离，渲染进程沙箱化，IPC 经过校验。
- Univer OSS 电子表格渲染器。
- 桌面外壳：内嵌式红绿灯按钮、带 AutoSave 胶囊和保存/撤销/重做的工具栏、无 File 选项卡的功能区（文件命令位于 macOS 应用菜单中）、名称框 + 公式栏、工作表标签、可折叠 AI 面板。
- Rust sidecar，用于流式读取 XLSX 元数据和有界工作表区域。
- 视口驱动的加载，渲染单元格窗口有界。
- 只读 XLSX 单元格样式、嵌入图片和锚定图表可视化。
- 基于缓存的柱状图、条形图、折线图、饼图和柱线组合图渲染。
- 带版本、经 Schema 校验的工作簿命令 DSL。
- 确定性本地规划器，用于可重复的 AI 工作流测试。
- 无副作用预览、原子事务、修订冲突检测和撤销。
- XLSX 包清单和精准工作表变更。
- 对流式外部工作簿进行单元格值、公式和功能区样式编辑，保存/另存为（⌘S / ⇧⌘S）时做保留性校验；样式变更以写时复制方式写入 styles.xml。
- 在完全加载的工作簿上插入/删除行列、合并/取消合并，回放到文件时进行引用偏移（包括其他工作表的公式、定义名称和图表系列），并对表格、锚定图表和已删除引用做失败关闭保护。
- 外部工作簿的工作表管理：重命名（公式、定义名称、图表系列和超链接锚点中的限定引用在文件侧重写）、添加空白工作表（创建 part + content-type + relationship，立即可编辑）、删除（当公式、图表或定义名称仍引用该工作表，或该工作表带有绘图/表格时，失败关闭）。
- 在完全加载的工作簿上进行交互式排序和筛选，保存回 autoFilter XML（值列表、空白标志、自定义条件）以及声明式行可见性；颜色筛选和表格自有筛选失败关闭。
- 逐边边框编辑、完整的字体/填充/边框颜色选择器和填充清除，以写时复制方式写入样式表的 borders/fills 表。
- 行高、列宽、自动适应重置和隐藏行/列保存为有序的轴属性操作；向下/向右填充和清除内容/格式/全部（格式清除将单元格重置为文件中的默认样式）。
- 图表编辑（标题、柱状/条形/折线/面积类型转换、系列颜色），支持精准图表 part 补丁和实时 SVG 预览。
- 对未触及的 OOXML 条目做保留性校验。
- 生成的兼容性测试夹具。

## 运行

```bash
brew install rust
npm install
npm run dev
```

本地规划器接受：

- `set A1 to 42`
- `formula B4 = SUM(B2:B3)`
- `rename sheet to Budget`

## 界面

桌面布局遵循成熟的电子表格惯例，降低 Excel 用户的迁移成本。依赖不支持的工作簿功能的功能区区域已预留，但不作为可用命令呈现。布局、AI 交互模型和当前视觉限制见 [docs/interface.md](docs/interface.md)。

## 安全边界

渲染进程无法访问 Node.js 或文件系统。AI 输出视为不可信输入，必须通过 DSL Schema、修订检查、试运行预览和显式批准。有意排除了任意 JavaScript 和 Python 执行。

UI 以流式模式打开外部 XLSX 包。Rust sidecar 将工作表 XML 索引为临时行块，Univer 仅持有当前视口及其缓冲区。样式附加到流式单元格上。绘图关系、图表缓存、锚点和图片元数据从其小型 OOXML part 中读取，无需将大型工作表加载到内存。嵌入图片字节通过单独的限大小 IPC 请求获取。单元格编辑在渲染进程中记录日志，并通过主进程保存，主进程校验磁盘文件哈希，仅重写被编辑的工作表条目，若其他任何包条目会发生变化则失败关闭。演示工作簿保留本地 AI 预览、事务和撤销工作流。

运行大型工作簿门禁：

```bash
npm run benchmark:large -- "/path/to/workbook.xlsx"
```
