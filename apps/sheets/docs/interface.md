# 桌面界面

桌面外壳遵循熟悉的电子表格惯例，因此现有 Excel 用户可以沿用他们的导航习惯，而无需学习新的工作区模型。它使用自己的产品标识，不复制 Microsoft 的资产或商标。

## 布局

外壳布局从上到下依次为：

1. 一行浅色工具栏，内嵌 macOS 红绿灯按钮（`titleBarStyle: hiddenInset`）、一个自动保存胶囊按钮（关闭 — 本地文件）、保存/另存为/撤销/重做图标、居中的工作簿名称及保存状态，以及打开 XLSX。该行是窗口拖动区域。
2. 功能区选项卡：开始、插入、页面布局、公式、数据、审阅、视图和 AI。没有文件选项卡——文件命令位于 macOS 应用程序菜单中（文件 → 打开 ⌘O / 保存 ⌘S / 另存为 ⇧⌘S），通过 IPC 转发到渲染进程。
3. 一个紧凑的单带功能区，带有细线组分隔符，没有组标题（组名保留为 `aria-label`）。开始选项卡包含剪贴板、字体、对齐、数字、样式、单元格和编辑组。
4. Univer 的名称框 + 公式栏（预设 `header: true, toolbar: false` 仅渲染这些）、工作表画布、工作表标签、统计信息和缩放控件。
5. 右侧的工作簿 Copilot 面板，可折叠为窄栏。

功能区确立了最终的命令层级。工作簿能力尚未实现的命令以预留界面的形式呈现，而非可执行操作。在开发构建中，应用程序菜单标题显示为 "Electron"——修复该问题需要打包构建（P0）。

## AI 交互

AI 面板从属于工作表，可折叠以最大化工作空间。本地演示支持：

- 自然语言命令规划；
- 变更前预览；
- 显式应用或丢弃；
- 带版本的回退。

外部 XLSX 文件支持直接编辑单元格值/公式以及功能区样式编辑，并在保存时进行保留检查后写回。AI 编辑仍仅限演示：面板的 AI 输入对导入文件禁用，并显示保存/流式传输状态。

## 大型工作簿

打开 XLSX 时，Univer 中仅创建工作表骨架。可见范围和有限缓冲区从 Rust sidecar 加载。切换工作表和滚动时请求新的稀疏范围，同时清除之前的渲染范围。

因此，UI 对小型和大型文件保持相同的工作表、公式栏和标签导航模型，而无需将所有单元格加载到渲染进程中。

## 工作簿视觉效果

流式单元格显示其源字体、填充、对齐和数字格式，前提是这些值可以直接从 `styles.xml` 解析。

图像和图表在用户滚动时保持锚定到工作表范围。嵌入图像按需加载。柱状图、水平条形图、折线图、饼图和条形-折线组合图从 XLSX 包中存储的缓存系列渲染。这是只读兼容视图，而非可编辑的原生图表设计器。

## 当前限制

主要的界面级差距：

- 行/列插入/删除和合并/取消合并仅在完全加载的工作簿（≤50k 单元格）上保存；包含表格或锚定图表的工作表在保存时失败关闭（跨工作表引用会自动重写）；
- 工作表重命名/添加/删除可在任何外部工作簿上保存；范围移动仍被阻止；
- 完整的 Excel 图表主题、效果、3D 变体和图表/图像编辑面板；
- 图案填充编辑和对角边框控件（边缘边框、完整颜色选择器和填充清除已发布）；
- 页面布局和打印配置。

不支持的绘图形状以占位符形式呈现。相应的编辑控件保留用于后续的兼容性里程碑。
