# 格式化指南（formatting）

## 操作定义

`{op:"format_range", sheetId, range:"A1:C1", format:{…}}` — format 至少需要一个字段；字段值为 **null 表示清除该属性**：

- `bold` / `italic` / `underline` / `strikethrough`：布尔值或 null
- `fontFamily`：字体名称（例如 "Calibri"、"微软雅黑"）或 null
- `fontSize`：磅值（1–409）或 null
- `fontColor` / `fillColor`：6 位十六进制（"#RRGGBB"）或 null
- `numberFormat`：Excel 格式字符串（例如 "0.00%"、"#,##0.00"、"yyyy-mm-dd"）或 null（恢复为常规格式）
- `horizontalAlign`："left" | "center" | "right" 或 null
- `verticalAlign`："top" | "center" | "bottom" 或 null
- `wrapText`：布尔值或 null（自动换行）
- `textRotation`：-90 到 90 的整数（正值为逆时针）或 "vertical"（竖排堆叠文本）或 null
- `indent`：缩进级别 0–250（0 表示清除），在屏幕上渲染为左内边距并写入文件
- `border`：{type:"all"|"top"|"bottom"|"left"|"right"|"none", color?:"#RRGGBB"} — **按单元格边缘**语义（范围内每个单元格都获得该边缘）；"none" 清除所有边框

每个范围一个操作（范围级，最多 200,000 个单元格 — 对大文件的整个数据列进行格式化没有问题）；当你需要"复用某处的格式"时，先用 read_formats 读取当前状态。

## 数字格式

- 百分比：通常用 `0.0%`/`0.00%`；占比列（合计为 100%）至少用 `0.000%`
- 大数字：`#,##0`；同一列内保持小数位数一致
- 日期：`yyyy-mm-dd`

### 货币必须锁定区域设置（关键，最常见的错误）

**切勿使用裸 `$#,##0.00`** — 中文区域设置的 Excel 会将裸 `$` 重新映射为 `¥`，导致美元表格显示人民币符号。始终使用带方括号的区域前缀强制指定货币符号：

- 美元：`[$$-409]#,##0.00`（或整数 `[$$-409]#,##0`）
- 人民币：`[$¥-804]#,##0.00`
- 欧元：`[$€-x-euro2]#,##0.00`
- 英镑：`[$£-809]#,##0.00`

在千/百万量级下，小数通常为 0（`[$$-409]#,##0`），单位在表头中注明（例如 "Amount (thousands)"）。

### 负数和零（财务表格强制要求）

- 负数用红色括号表示：`[$$-409]#,##0;[Red]([$$-409]#,##0)`
- 零显示为短横线（区分"0"和"空白 = 缺失数据"）：`[$$-409]#,##0;[Red]([$$-409]#,##0);"-"`
- 三段式格式字符串语义：`正数;负数;零`；纯数字版本：`#,##0;[Red](#,##0);"-"`

> 财务报表/会计表格的完整规范（层级、合计行、GAAP 顺序、配色）见 `financial-formatting` 指南。

## 表格样式规则（当用户没有明确的样式要求时）

- **表头是强制性的**：任何数据网格都不能是裸露的数字矩阵 — 必须有列标题（维度/期间/指标名称），交叉表还需要行标题。表头加粗 + 浅色填充（例如 #F2F2F2 或 #D6E4F0）。
- **对齐**：数字右对齐，文本左对齐，日期居中或左对齐；同一列内和同一表格内严格一致。
- **克制的字号**：正文使用一种字号；章节标题最多大一级；切勿在一个表格主体内混用多种字号。
- **合计/小计行**：用加粗或浅色填充突出显示；不要过度装饰。
- **颜色可访问性**：保持文本与背景之间的高对比度；避免刺眼的高饱和度配色，除非用于强调关键值。
- **财务模型惯例**（当用户正在构建财务模型或要求专业格式化时）：硬编码输入用蓝色 #0000FF，公式计算用黑色，跨表引用用绿色 #008000。
- **样式失败绝不阻塞**：如果格式类操作被拒绝，优先交付正确的数据；不要反复重试样式设置。
