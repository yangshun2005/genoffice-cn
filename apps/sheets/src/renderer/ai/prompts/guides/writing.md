# 内容编写指南（writing）

## 操作定义

- `{op:"set_cell", sheetId, address:"B2", value}` — 写入单个值（字符串/数字/布尔值/null）。可选的 `expectedValue` 用于并发保护。
- `{op:"set_formula", sheetId, address, formula:"=SUM(A1:A10)"}` — 写入公式，必须以 = 开头。可选的 `expectedFormula`。
- `{op:"clear_cell", sheetId, address}` — 清除单个单元格。
- `{op:"set_range", sheetId, start:"B2", values:[[row1], [row2], …]}` — 批量写入：按行排列的二维数组，从 start 开始向右、向下展开。**values 必须是矩形——每一行长度相同**（用 null 清除某个单元格；较短的行会静默留下旧内容）。除了 start，你也可以传入 `range:"B2:D5"`，其大小必须与 values 完全匹配。**以 = 开头的字符串会作为公式写入。** 连续区域始终使用 set_range；绝不要将其拆分为多个 set_cell 操作。
- **重写现有表格的行时，要覆盖完整的行跨度**：values 的各行应覆盖表格的所有列（或者该写入操作应与 clear_range 配合以清除剩余单元格），这样旧内容就不会有残留片段与新内容并存。
- `{op:"fill_range", sheetId, source:"B2", target:"B2:B88588", sourceSheetId?}` — 填充/复制，相当于将 Excel 的填充柄作为一个操作：源块的值**和公式**会平铺到目标区域。相对引用按每次复制进行偏移（=A2+1 向下填充变为 =A3+1、=A4+1……）；`$` 锚定的轴保持固定。**这是将公式或模式向下填充整列的唯一方式**——一个小操作，而不是逐行写出数千个 set_range。规则：先写入/验证源单元格，然后填充；源 ≤ 2000 个单元格；目标最多 **200,000 个单元格**，且每个维度都是源维度的整数倍；重叠的源必须位于目标的左上角（向下/向右填充会将源作为第一个平铺块）；`sourceSheetId` 允许源位于另一个工作表上（在工作表之间复制表头行）。每次复制都会重新扫描大范围绝对引用的公式填充（=SUM(B$2:B$88588)、针对大表的查找）会被拒绝——请使用相对引用，使每一行只涉及自身的单元格。
- `{op:"copy_range", sheetId, source:"A1:F5000", target:"H1", sourceSheetId?, filterColumn?, filterValues?}` — 将一个块精确复制到一个目标位置一次（相当于将 Excel 复制 → 粘贴作为一个操作），包括值**和公式**；相对引用按块的偏移量进行偏移，`$` 锚定的轴保持固定。在大型流式工作簿（缓存值模式）上，公式在共享引擎预算内实时携带（其引用的文件单元格按需加载）；当被复制公式的引用超出该预算——或某个公式实时求值过于昂贵——复制操作会改为写入源单元格的当前值，结果中会注明有多少公式单元格被冻结以及原因。`target` 是目标的左上角单元格（或与源大小完全相同的区域）。与 fill_range 不同，它没有平铺，且源可以很大——最多 **200,000 个单元格**——因此这是复制大表或移动某列数据的唯一方式（源和目标不得重叠；`sourceSheetId` 可跨工作表复制）。
- **筛选复制（行提取）**：使用 `filterColumn`（源区域内某列的绝对列字母）和 `filterValues`（1–100 个字符串），copy_range 只复制**该列单元格匹配其中一个值的源行**（按文本比较，去除首尾空格，不区分大小写），在目标处紧凑排列、无间隙，作为**静态值**（公式不会被携带）。`target` 必须是单个锚点单元格。它逐块读取真实文件数据，因此适用于 FILTER 风格公式被拒绝的大型流式工作簿。这是按某列的值拆分大表的唯一方式：先对列执行 aggregate_range 以获取不同值及计数，用 add_sheet 为每个目标创建 `rows` 大小等于其计数（加表头）的工作表，用普通 copy_range 复制表头行，然后对每个值执行一次筛选 copy_range，目标锚定在表头下方。匹配零行的筛选会报错失败（请检查实际的单元格值）；匹配数超过目标工作表网格也会失败，并告知你需要的行数。
- `{op:"convert_to_values", sheetId, range:"B2:B88588"}` — 将公式冻结为其当前计算值（相当于 Excel 的复制 → 粘贴为值），最多 **200,000 个单元格**。只有公式单元格会改变；值、文本和格式保持不变。当用户要求"移除公式但保留结果"时，或在删除公式引用的源数据之前使用。它读取网格**当前**持有的内容，因此不能与写入公式到其范围内的操作放在同一批次（会被拒绝）——在一个批次中写入公式，验证结果，然后在后续批次中转换。
- `{op:"clear_range", sheetId, range:"A1:C10"}` — 清除一个矩形区域（最多 200,000 个单元格——整列也可以）。

限制：每批次最多 2000 个展开的单元格更改——区域级操作 fill_range / copy_range / convert_to_values / clear_range / find_replace / format_range 不受此限制，每个最多可处理 200,000 个单元格。

## 公式规则

- **始终将计算交给公式**——绝不要自己计算值并硬编码；当源数据变化时，表格应自动更新。
- **不要在大范围上使用数组条件公式**：条件/查找函数将大范围作为其逐元素参数的公式——例如去重计数惯用法 `SUMPRODUCT(1/COUNTIF(A2:A88588,A2:A88588))`——会以二次方复杂度求值，导致应用冻结，会被拒绝。对于去重计数/频率统计，请使用 aggregate_range 工具并以文本形式报告答案。
- 如果引用可以用相对/绝对引用（$）表示，就不要写常量。
- 与现有约定保持一致：如果前面的行使用公式，新行也使用公式；如果前面的税额为负数，新填充的也应为负数。

**错误**——心算后硬编码：

```json
{ "op": "set_cell", "sheetId": "s1", "address": "B10", "value": 5000 }
```

**正确**——让表格来计算：

```json
{ "op": "set_formula", "sheetId": "s1", "address": "B10", "formula": "=SUM(B2:B9)" }
```

## 份额/百分比列（总计必须为 100%）

- 在单元格中保持完整精度：使用类似 `=B4/SUM($B$4:$B$8)` 的公式——**不要**逐行写入四舍五入后的常量，否则总计会显示为 100.1% 或 99.9%。
- 四舍五入属于显示格式（format_range 的 numberFormat，至少 `0.000%`），而不属于存储值。

## 值与单位

- 比率/增长率/份额及其他相对值以 **(0,1) 之间的小数**存储（0.1234 表示 12.34%）；如果源数据是像 26.64 这样的百分数，写入前除以 100。
- 在同一列中保持单位、小数位数和货币符号一致；在表头或标题中注明单位（例如"金额（百万美元）"）。
- 日期：优先写入 ISO 格式（2026-07-23）+ 控制显示的数字格式。

## 查找与替换（find_replace）

`{op:"find_replace", sheetId, range:"A1:D50", find:"old text", replace:"new text", matchCase?, wholeCell?}`

- 仅替换**文本值**：公式单元格和数字不受影响。
- 默认不区分大小写（matchCase:true 启用区分大小写）；使用 wholeCell:true 时，仅当单元格的整个内容完全匹配时才替换。
- range 为必填，最多 **200,000 个单元格**（整个已用列也可以）。≤2000 个单元格的区域会展开为逐单元格编辑（预览/撤销与手动输入一致），且必须先加载；更大的区域作为一次区域级扫描应用，自行加载每个区域。
