# PDF：阅读、注释与密文遮盖

PDF 编辑器在功能区有五个选项卡：**开始 / 注释 / 编辑 / 页面 / 视图**。可读可写：文本可编辑，内容可遮盖和签名，表单可填写。

## 阅读与导航

- 左侧边栏：**缩略图**（点击跳转，可见范围高亮显示）或**大纲**（书签，存在时显示）。
- 缩放：右下角的比例控件；ctrl+滚轮逐步调整缩放。
- 旋转：从页面菜单按页或全部页面旋转；保存时旋转会写回文件。
- 搜索：ctrl+F 全文搜索，所有匹配项高亮显示。
- 加密 PDF：弹出密码输入框（独立小窗口）即可打开；密码仅在本次会话中使用。

## 文本选择与标记（注释）

在任意段落上试试：

1. **用鼠标拖选一句话**：松开后，上方浮出注释工具栏：

![选中文本后的注释工具栏](img/pdf-highlight.png)

2. 选择**高亮**（黄色样本会打开调色板）、**下划线**或**删除线**；**询问 AI** 将选中内容连同问题发送到 AI 面板。
3. 撤销注释：重新拖选同一片段，点击工具栏中已激活的按钮（类似 Word 的开关），或选中后按 Delete。

参考：

- 在文本上拖动会弹出工具栏：**高亮 / 下划线 / 删除线 / 复制 / 询问 AI**。
- 颜色来自调色板；**对已标记的范围再次应用同一标记会将其移除**（类似 Word 的开关）。
- 文件中已保存的标记可以选中并删除（⋯ 菜单或 Delete）。
- **注意**：绘图工具激活时，文本层无法选中；每次放置后工具会自动关闭，下次操作前需切回选择模式。

## 绘图工具（注释）

六种工具：**画笔、矩形、椭圆、箭头、便签**，以及注释选项卡中的**遮盖区域**。

- 每种工具都是开关：点击激活；**放置一个形状后自动关闭**（再次点击工具可继续）；点击已激活的工具也会将其关闭。
- 自由绘制跟随笔画粗细；矩形/椭圆/箭头通过拖动绘制；颜色来自绘图调色板。
- 已放置的形状可以选中、删除、拖动，矩形/椭圆还可调整大小。
- **遮盖的完整流程**（用于隐藏一行文本）：

  1. 注释选项卡 ▸ 点击**遮盖区域**（工具激活）。
  2. **在内容上拖出一个矩形**：内容被斜线标记覆盖，工具栏出现**清除标记 / 应用遮盖**按钮：

  ![标记遮盖后的页面](img/pdf-redact.png)

  3. 点击**应用遮盖**并确认：结果是生成一份工作副本，被覆盖的文本和图像已被物理删除（不只是隐藏），且无法撤销；原始文档保持不变。

  弄错了？清除标记按钮会删除当前标记，让你重新绘制。

## 便签与评论串

- **便签工具**钉上图钉，并在边距为该文本打开一张卡片（作者名可配置）；确认后保存为标准 PDF 文本注释。
- 点击图钉打开评论串：**回复**（类似 WPS/Acrobat 的平铺评论串）、**编辑**自己的评论、**删除**单条评论或整个评论串。
- 未完成的编辑会保留，直到保存时将新文本写入文件中同一注释，从而保持回复串完整。

## 编辑 PDF 内容（编辑）

- **编辑文本**：点击文本逐块编辑（pdfium 引擎；字体尽可能适配）。
- **插入文本**：放置可定位的文本，可自选字体、大小和颜色。
- **插入图像 / 图章**。
- 表单：AcroForm 字段可直接填写；保存时写入值。

## 签名

- **手写签名**：手绘签名；可绑定到表单签名字段。
- **图像签名**：放置一张图片作为签名。
- 已保存的签名可重复使用。
- **证书签名**（注释选项卡）：使用系统证书存储中的证书或 .p12/.pfx 文件签名；可选择在页面上显示签名，并可选择对文档进行认证以防止后续更改。
- 签名始终写入**新文件**（增量更新——之前的签名仍然有效），并在原位置打开签名后的副本。请先保存：签名覆盖的是磁盘上的当前文件。
- 文档上方的横幅列出已有签名；**查看签名**显示每个签名的有效性、覆盖范围和证书链。不检查吊销状态（CRL/OCSP）。

## 页面操作（页面）

- **旋转 / 删除 / 重排**：拖动缩略图重排；删除会请求确认。
- **导入页面**：从另一个 PDF 拖入页面。**插入空白页**添加一个空页面。
- **替换页面**用另一文档的页面替换一个范围；**裁剪页面**裁掉边缘，可选择应用于所有页面。
- **页面大小**将所有页面重新缩放到同一纸张尺寸；**反转顺序**将文档从头到尾翻转。
- **提取页面**：将选中的页面导出为新的 PDF。
- **拆分 PDF**：两种方式——按范围拆分为多个文件，或将每页切成更小页面的网格。
- **合并 PDF**：两种方式——追加其他 PDF，或将多页合并到同一张纸上。读取前先汇总大小，**总计超过 1 GiB 一律拒绝**并给出可读的错误（从而限制内存占用）。
- 页面级更改在下次保存时写回；另存为保持原始文件不变。

## 导出与打印

- **导出为 Word… / PowerPoint… / Excel…** 在文件菜单中，或从功能区的**转换 PDF** 执行同样三项——全部本地完成，不上传任何内容。.pptx 每页一张幻灯片，.xlsx 每页一个工作表。每项都会询问保存位置。
- **打印**：通过系统对话框按当前顺序和旋转打印；支持页面范围。

## 保存

- 普通保存或自动保存会将注释和编辑写回文件（原子操作）。
- **遮盖需经过其应用流程**，该流程生成副本并保持原始文件不变，以免敏感内容残留在其中。
