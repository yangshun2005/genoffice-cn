# 字体：系统字体与可下载字体家族

## 字体列表

字体控件位于每个编辑器的 Home 标签页（下图为 Slides 中的字体组）：

![Slides 功能区中的字体组](img/fonts.png)

每个编辑器的字体选择器合并了：本地已安装字体 + 平台常见候选字体（常见的 Windows 和 macOS 字体家族，涵盖西文和 CJK，包括 CJK 字体在其原生系统上报告的本地化名称）。当系统能枚举本地字体时，列表按实际存在的字体分组；否则退化为完整的候选列表。

## 可下载字体（Slides）

- Slides 字体选择器会打开一个**字体目录**：精选的 OFL 字体集合，覆盖多种文字；每个家族都提供常规和粗体字重。
- 选择后从 CDN 下载并安装（校验和锁定）到应用的字体存储中——之后所有文档均可使用，无需系统级安装。
- 安装文件存放在应用私有目录中，随应用一同删除。

## CJK 排版

- Docs 中的 CJK 字体支持与 Word 对齐的标点压缩和禁则换行规则（参见 Docs 章节）。
- 目录中的 CJK 字体家族涵盖简体/繁体中文、日文和韩文，包含衬线和无衬线。

## 管理本地字体

- 安装本地字体文件入口可将磁盘上的 .ttf/.otf 文件加载到应用字体存储中。
- 存储按字体家族归档；同一家族的多个字重可共存。
