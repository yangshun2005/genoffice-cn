# PDF：阅读、注释与涂黑

PDF 编辑器在功能区有五个选项卡：**Home / 注释 / 编辑 / 页面 / 视图**。它可读可写：文本可修改，内容可涂黑和签名，表单可填写。

## 阅读与导航

- 左侧边栏：**缩略图**（点击跳转，可见范围高亮显示）或**大纲**（书签，如有）。
- 缩放：右下角的比例控件；ctrl+滚轮按档位缩放。
- 旋转：可在页面菜单中按单页或全部旋转；旋转会在保存时写回。
- 搜索：ctrl+F 全文搜索，所有匹配项高亮显示。
- 加密 PDF：会弹出密码输入框（独立小窗口）打开；密码仅用于本次会话。

## 文本选择与标记（注释）

在任意段落上试试：

1. **用鼠标拖选一句话** — 松开后文本上方出现注释栏：

![选中文本后的注释栏](img/pdf-highlight.png)

2. 选择**高亮**（黄色色块打开调色板）、**下划线**或**删除线**；**询问 AI** 将选中内容连同你的问题发送到 AI 面板。
3. 取消注释：重新拖选同一段文字，点击注释栏上已激活的按钮（类似 Word 的开关），或选中后按 Delete。

需要了解的行为：

- 拖选文本会弹出浮动栏：**高亮 / 下划线 / 删除线 / 复制 / 询问 AI**。
- 颜色来自调色板；**对已标记的区间再次应用相同标记会将其移除**（类似 Word 的开关）。
- 文件中已保存的标记可选中并删除（⋯ 菜单或 Delete）。
- **注意**：绘图工具激活时，文本层不可选中 — 每次插入后工具会自动关闭，方便你回到选择模式进行下一步操作。

## 绘图工具（注释）

六个工具：**墨水、矩形、椭圆、箭头、便签**，以及注释选项卡中的**涂黑框**。

- 每个工具都是开关：点击激活；**放置一个形状后自动关闭**（要继续就再次点击工具）；点击已激活的工具也会将其关闭。
- 墨水跟随笔画粗细；矩形、椭圆和箭头通过拖拽绘制；颜色来自绘图调色板。
- 已放置的形状可选中、删除、拖动，矩形和椭圆还可调整大小。
- **涂黑，完整流程**（用于隐藏一行文本）：

  1. 注释选项卡 ▸ 点击**涂黑区域**（工具激活）。
  2. **在内容上拖出一个框** — 会被虚线标记覆盖，工具栏出现**清除标记 / 应用涂黑**按钮：

  ![标记涂黑后的页面](img/pdf-redact.png)

  3. 点击**应用涂黑**并确认 — 结果是生成一份工作副本，被覆盖的文本和图像被物理移除（而非简单遮盖），且操作不可撤销；原始文档保持不变。

  弄错了？清除标记按钮会删除当前标记，你可以重新绘制。

## 便签与评论串

- **便签工具**放置一个圆点并打开侧边栏输入文本（作者名可配置）；确认后保存为标准 PDF 文本注释。
- 点击圆点打开评论串：**回复**（扁平评论串，类似 WPS/Acrobat）、**编辑**你的评论、**删除**某条评论或整个评论串。
- 未保存的修改在保存前一直有效，保存时会将新文本写入文件中的同一注释，回复链保持不变。

## 编辑 PDF 内容（编辑）

- **编辑文本**：点击文本按块编辑（pdfium 引擎；尽可能匹配字体）。
- **插入文本**：以你选择的字体、大小和颜色插入可搜索文本。
- **插入图像 / 图章**。
- 表单：AcroForm 字段可直接填写；值在保存时写入。

## 签名

- **手写签名**：手绘；可关联到表单的签名字段。
- **图片签名**：放置一张图片作为签名。
- 已保存的签名可重复使用。
- **证书签名**（注释选项卡）：使用系统证书库或 .p12/.pfx 文件中的证书签名；可选择在页面上显示签名，并可选对文档进行认证以防后续修改。
- 签名始终写入**新文件**（增量更新 — 之前的签名仍然有效），并在原位置打开签名后的副本。请先保存：签名覆盖的是磁盘上的文件。
- 文档上方的横幅列出已有签名；**查看签名**显示每个签名的有效性、覆盖范围和证书链。不验证吊销状态（CRL/OCSP）。

## 页面操作（页面）

- **旋转 / 删除 / 重排**：拖动缩略图重排；删除会要求确认。
- **导入页面**：从另一个 PDF 导入页面到文档中。**插入空白页**添加一个空白页。
- **替换页面**用其他来源的页面替换一个区间；**裁剪页面**裁剪边缘，可选择应用到所有页面。
- **页面尺寸**将每页调整为统一的纸张大小；**反转顺序**将文档从头到尾翻转。
- **提取页面**：将选中的页面导出为新 PDF。
- **拆分 PDF**：两种形式 — 按区间拆分为多个文件，或将每页切成更小页面的网格。
- **合并 PDF**：两种形式 — 追加其他 PDF，或将多页合并到一张纸上。尺寸在读取任何内容**之前**累加，总计超过 **1 GiB 会被拒绝**并给出可读错误（以限制内存占用）。
- 页面级修改在下次保存时写回；另存为… 不会改动原始文件。

## 导出与打印

- 文件菜单中的**导出为 Word… / PowerPoint… / Excel…**，或功能区**转换 PDF** 中的同样三项 — 全部本地处理，无上传。.pptx 每页一张幻灯片，.xlsx 每页一个工作表。每项都会询问保存位置。
- **打印**：按当前顺序和旋转通过系统对话框打印；支持页面范围。

## 保存

- 常规保存，无论手动还是自动，都会将注释和修改写回文件（原子操作）。
- **涂黑走自己的应用流程**并生成副本，原始文件保持不变，敏感内容不会留在其中。
