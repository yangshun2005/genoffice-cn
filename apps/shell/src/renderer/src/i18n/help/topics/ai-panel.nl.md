# AI 助手面板

每个编辑器都可以调出 AI 面板：选中内容，输入指令，即可看到流式输出结果。

## 打开与使用

![Docs 中的 AI 面板](img/ai-panel.png)

- 入口：每个编辑器工具栏上的 **AI 按钮**、右键菜单中的 **询问 AI**，或选区浮动栏上的询问 AI。
- 用自然语言描述任务（重写这段 / 把这列改成百分比 / 重新计算此页……），按 Enter。
- 回答以**流式**显示；AI 需要工具时（读取文档、编辑文档），会执行后继续，直到完成。
- **停止**：随时中断当前轮次。
- **队列**：回答流式输出期间，按 Enter 会把消息加入队列而非丢弃——输入框上方会显示计数条；打开后可编辑、删除、重排、暂停或清空。当前轮次结束后自动发送下一条；Esc 仍可停止当前轮次。

## 能做什么

- **Docs**：重写/扩写/翻译/摘要，插入表格和图片，调整格式；每轮先创建快照。
- **Sheets**：公式、填充数据、批量转换、格式设置。
- **Slides**：生成整套演示文稿、调整版式、重写文本。
- **PDF**：基于选中文本或页面进行问答和摘要。
- **Markdown / HTML**：重写、扩写、翻译。
- **开始 ▸ 询问 AI** 会从带星标的文件中作答并引用它们——知识库面板在“开始”章节有独立小节，Docs 的 AI 面板具备同样的能力。

## 回滚与安全

- Docs 中的面板维护一份**版本列表**：每轮一个快照，可回退到任意一个，且回退本身可用 Ctrl+Z 撤销。重新打开文档后快照依然保留。
- AI 编辑走与手动编辑相同的编辑路径（可撤销，仅在保存时落盘）——不会跳过你的保存确认。

## 对 AI 隐藏选区

- 在 Slides、HTML 和 Markdown 中，可让选区不被模型看到：右键 ▸ **对 AI 隐藏选区**，为占位符命名，模型在该位置读到的是 `{{名称}}`。（Markdown 通过工具栏上的眼睛关闭开关启用该项；HTML 的开关在源码面板中。）
- 文件保留真实文本——保存、导出和打印不受影响，重新打开后标记依然有效。同一菜单项可恢复可见（Markdown 有单独的 **向 AI 显示选区** 项）。
- HTML 隐藏元素内容、属性值和脚本中的字符串字面量；渲染后的页面始终不变。
- Slides 还会隐藏整张图片、视频和音频，含隐藏内容的幻灯片绝不会作为截图发送：自动版式检查会跳过该页并报告。
- 仅对应用内 AI 生效——CLI、MCP 工具和无头导出直接读取文件，仍能看到文本。

## 隐私

- 指令和相关文档内容会发送到**你设置的模型服务**（Genspark 托管或自建端点，见下一章）；未设置则不会发送任何内容。
- 本地文件不会上传到其他地方；BYOK 密钥保存在本机应用设置文件中，仅在请求头中发送。
