# PDF：阅读、注释与密文遮盖

PDF 编辑器在工具栏上有五个标签页：**主页 / 注释 / 编辑 / 页面 / 视图**。它同时支持读写：可以编辑文本、遮盖内容、签名、填写表单。

## 阅读与导航

- 左侧边栏：**缩略图**（点击跳转，并高亮可见范围）或**大纲**（书签，若有）。
- 缩放：右下角的比例工具；按住 ctrl 滚动鼠标滚轮可逐步缩放。
- 旋转：可从页面菜单对单页或全部页面旋转；保存时会写入旋转信息。
- 搜索：ctrl+F 全文搜索并高亮所有结果。
- 加密 PDF：打开时弹出密码输入框（独立小窗口）；密码仅在当前会话中使用。

## 文本选择与标记（注释）

在任意段落上试试：

1. **用鼠标拖选一句话** — 松开后文本上方出现浮动注释栏：

![选中文本后的注释栏](img/pdf-highlight.png)

2. 选择**高亮**（黄色方块打开调色板）、**下划线**或**删除线**；**询问 AI** 会将选中内容连同你的问题发送到 AI 面板。
3. 要取消注释，再次拖选同一片段并点击工具栏上已激活的按钮（Word 风格的切换开关），或选中后按 Delete。

补充说明：

- 在文本上拖动会弹出工具栏：**高亮 / 下划线 / 删除线 / 复制 / 询问 AI**。
- 颜色来自调色板；**对已标记范围应用同一标记会将其移除**（Word 风格的切换开关）。
- 文件中已保存的标记可以选中并删除（⋯ 菜单或 Delete）。
- **注意**：绘图工具激活时无法选择文本层——工具每次放置后会自动禁用，回到选择模式以便下一步操作。

## 绘图工具（注释）

六种工具：**自由绘制**、**矩形**、**椭圆**、**箭头**、**便签**，以及注释标签页中的**区域密文遮盖**。

- 每个工具都是切换开关：点击激活；**放置图形后自动禁用**（再次点击工具可继续）；点击已激活的工具也会将其禁用。
- 墨迹跟随线宽；矩形、椭圆、箭头通过拖动绘制；颜色来自绘图调色板。
- 已放置的图形可以选中、删除、拖动和调整大小（矩形和椭圆）。
- **遮盖内容，完整流程**（用于遮盖一行文本）：

  1. 注释标签页 ▸ 点击**区域密文遮盖**（工具激活）。
  2. **在内容上拖出一个方框** — 覆盖斜线标记，工具栏出现**清除标记**和**应用密文遮盖**两个按钮：

  ![标记密文遮盖区域后的页面](img/pdf-redact.png)

  3. 点击**应用密文遮盖**并确认 — 结果是工作副本，被覆盖的文本和图像会被真正删除（而非仅覆盖），且无法撤销；原始文档保持不变。

  弄错了？清除标记按钮会抹去当前标记，让你重新绘制。

## 便签与评论串

- **便签工具**放置一个图钉并在边栏打开卡片供输入文本（可设置作者名）；确认后保存为 PDF 标准文本注释。
- 点击图钉打开评论串：**回复**（WPS/Acrobat 风格的扁平评论串）、**编辑**你的评论、**删除**单条评论或整个评论串。
- 未提交的修改会保留，直到保存时将新文本写入文件中的同一条评论，回复串保持完整。

## 编辑 PDF 内容（编辑）

- **编辑文本**：点击文本以块为单位编辑（pdfium 引擎；字体尽可能匹配）。
- **插入文本**：放置可搜索的文本，字体、字号、颜色自选。
- **插入图片 / 印章**。
- 表单：AcroForm 字段可直接填写；保存时写入值。

## 签名

- **手写签名**：绘制签名；可绑定到表单中的签名字段。
- **图片签名**：将图片放置为签名。
- 可复用已保存的签名。
- **证书签名**（注释标签页）：使用系统证书库或 ‎.p12/.pfx‎ 文件中的证书签名；可选在页面上显示签名，可选认证文档以防后续更改。
- 签名写入始终生成**新文件**（增量更新 — 之前的签名仍然有效），并在原位置打开已签名副本。请先保存：签名覆盖的是磁盘上已保存的文件。
- 文档上方的横幅会统计现有签名；**查看签名**显示每个签名的有效性、覆盖范围和证书链。吊销状态 ‎(CRL/OCSP)‎ 不检查。

## 页面操作（页面）

- **旋转 / 删除 / 重排**：拖动缩略图重排；删除需确认。
- **导入页面**：从另一个 PDF 文件拖入页面到文档中。**插入空白页**添加一个空白页。
- **替换页面**用其他位置的页面替换某个范围；**裁剪页面**裁切边缘，可选应用于全部页面。
- **页面尺寸**将所有页面重新调整为统一纸张大小；**反转顺序**将文档从尾到头翻转。
- **提取此页**：将选中的页面导出为新的 PDF。
- **拆分 PDF**：两种形式 — 按范围拆分为多个文件，或将每页切成更小页面的网格。
- **合并 PDF**：两种形式 — 添加其他 PDF 文件，或将多页合并到一张纸上。所有尺寸在读取任何内容**之前**汇总，超过 **1 GiB** 的总量会被拒绝并给出明确提示（以限制内存占用）。
- 页面级更改在下次保存时写入；「另存为…」则保持原文件不变。

## 导出与打印

- 文件菜单中的**导出为 Word… / PowerPoint… / Excel…**，或工具栏中**转换 PDF** 的同样三项 — 全部本地处理，不上传。.pptx 文件每页一张幻灯片，.xlsx 文件每页一个工作表。每一项都会询问保存位置。
- **打印**：通过系统对话框按当前顺序和旋转打印；支持指定页面范围。

## 保存

- 普通保存和自动保存会将注释和修改重新写入文件（原子操作）。
- **密文遮盖走其专属的「应用密文遮盖」流程**，生成副本并保持原文件不变，以免敏感内容残留在其中。
