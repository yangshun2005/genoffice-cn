# Markdown 编辑器

Markdown 编辑器可打开 .md / .markdown——以及 .txt / .json，直接进入源码视图——同时显示源码和渲染后的预览。

- **打开**：从主页或 文件 ▸ 打开…；命令行也可用。
- **编辑**：纯文本编辑；GFM 扩展（表格、任务列表、删除线、自动链接）会在预览中渲染。
- **预览**：实时更新；图片等相对资源在文档旁边解析。
- **保存**：逐字节忠实——BOM、CRLF 和末尾空行都会保留；未修改的保存不会重写文件。
- **查找与替换**：ctrl+F 在源码中查找；全部替换会写入结果。
- **AI**：预设按钮让助手重写、扩展或翻译文档。选中内容可对 AI 隐藏（见 AI 面板章节）。

## 工具栏

编辑器上方的一行按钮（悬停查看说明）：

![Markdown 工具栏](img/md-toolbar.png)

- **文件与历史**：保存、另存为…、撤销、重做、查找；右侧的**自动保存**开关会定期将修改写入磁盘。
- **AI 按钮**：打开 AI 面板；旁边是重写 / 扩展 / 翻译预设。
- **段落样式**（下拉菜单）：从正文切换到各级标题。
- **行内格式**：**粗体**、_斜体_、~~删除线~~、`行内代码`、链接。
- **列表**：无序、有序、任务列表。
- **插入**：表格、图片、水平线。
- **属性**：插入或跳转到文件顶部的 YAML front matter 块。
- **大纲**：按标题层级跳转。
- **拼写检查**：为此文档开启或关闭拼写检查。
- **图床设置**：粘贴或拖入的图片先上传到你的存储——兼容 S3（R2/OSS/COS/MinIO）、SM.MS 或 GitHub——本地副本存入 assets 作为兜底。

三个快速示例：

- **标题**：光标放在该行 ▸ 段落样式下拉菜单 ▸「标题 1」。
- **表格**：点击**插入表格** ▸ 拖动选择行列数 ▸ 在单元格中输入；预览立即渲染。
- **任务列表**：选中几行 ▸ 点击**任务列表** ▸ 每行变为 `- [ ]`，预览中渲染为复选框。

## 导出

文件菜单，全部本地处理，且都会询问保存位置：

- **导出为 Word…** 和 **导出为 PDF…** 写出真正的 .docx 或 .pdf。
- **导出为图片…** 在你选择的文件夹中每页写出一个 PNG。
- **转换并在 Docs 中打开** 转换为 .docx 并在应用内的 Docs 标签页中打开：这不是上传到云端，转换后的副本留在缓存文件夹中，约一周后清理。

## 源码视图

功能区包含一个**源码**开关（随应用本地化）。开启后编辑器被原始 Markdown 替换：正是保存时写入的文本，不美化，不暗中规范化。

- **编辑忠实于字节。** 从源码视图保存产生的字节与从编辑器保存相同——BOM、CRLF 和末尾换行都会保留。
- **是同一个文档。** 可自由来回切换；源码就是编辑器本身的文本，不是需要合并的副本。
- **格式化工具栏不可用**，因为其中大多数按钮插入的是编辑器构造，只在渲染侧有意义。关闭视图后恢复。
- **.txt 和 .json** 直接以源码视图打开：没有可渲染的内容，所以源码_就是_文档。
