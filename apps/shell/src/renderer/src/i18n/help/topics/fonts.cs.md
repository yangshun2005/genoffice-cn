# 字体：系统字体与可下载字体家族

## 字体列表

字体控件位于每个编辑器的“主页”选项卡中（下图：Slides 中的字体组）：

![Slides 功能区中的字体组](img/fonts.png)

每个编辑器的字体选择器合并了：本地已安装字体 + 平台常见候选字体（Windows 和 macOS 最常见的字体家族，涵盖西文与 CJK，包括 CJK 字体在其系统中使用的本地化名称）。当系统能枚举本地字体时，列表按实际存在的字体分组；否则回退到完整候选列表。

## 可下载字体（Slides）

- Slides 的字体选择器会打开**字体目录**：精选的 OFL 字体集，覆盖多种字体体系；每个家族包含常规和粗体字重。
- 选择后，字体会从 CDN 下载并安装（附带校验和验证）到应用的字体存储中——此后对所有文档可用，无需在系统层面安装。
- 安装内容位于应用的私有目录中，随应用一同删除。

## CJK 排版

- Docs 中的 CJK 字体支持标点压缩和换行规则（禁则处理），与 Word 一致（参见 Docs 章节）。
- 目录中的 CJK 家族涵盖简体中文、繁体中文、日文和韩文，包括衬线和无衬线字体。

## 管理本地字体

- 安装本地字体文件的选项会从磁盘加载 .ttf/.otf 文件到应用的字体存储中。
- 存储按字体家族组织；同一家族的多个字重可以共存。
