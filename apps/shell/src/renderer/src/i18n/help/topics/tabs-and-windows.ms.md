# 标签页与窗口管理

所有打开的文件共用一个窗口。顶部的标签栏在它们之间切换，风格类似浏览器。

![标签栏：主页和两个文档](img/tabs.png)

## 基础操作

- **切换**：点击某个标签页，或在标签栏上滚动鼠标滚轮来循环切换。
- **关闭**：点击标签页上的 ×，或按 ⌘W/ctrl+W。如果有未保存的更改，会先询问你。
- **新建**：点击标签栏最右端的 +。
- **即时激活**：按下标签页立即切换，无需等待点击完成。

## 重命名：双击标签页

**双击任意文件标签页**，标题会就地变为输入框。按 Enter 确认，Esc 取消，失去焦点则确认。确认 IME 候选词的 Enter 不会被误认为确认。此重命名经过与主页行重命名相同的安全检查，即禁用字符和名称重复。磁盘上的文件会被重命名，最新列表会刷新。

## 拖拽重新排序

按住并拖动某个标签页到一侧即可重新排序。相邻标签页会直接让位，松开时顺序稳定。4 像素的死区防止普通点击导致标签页抖动。

## 上下文菜单

右键点击标签页可**在新窗口中打开**——每个可分离的文档标签页都提供此选项——以及**关闭**，在不可关闭的标签页上显示为灰色。两者均跟随应用语言。

## 分离为独立窗口

**将某个标签页拖出标签栏**（或使用在新窗口中打开），它会变成一个独立窗口，携带当前活动的文档。将其拖回即可重新贴入标签栏。分离出的窗口是完全对等的伙伴，你可以在那里继续编辑和保存。

## 所有标签页列表

当标签页超出空间时，标签栏最右端的小标签栏图标会打开完整列表。它是原生菜单，永远不会被内容区域遮挡，你可以用方向键选择。

## 每个编辑器内的工具栏

每个编辑器标签页顶部都有一个工具栏，布局因编辑器略有不同：

- **保存**（⌘S/ctrl+S）和**另存为…**。
- **撤销 / 重做**：多级，每个编辑器保存自己的历史。
- **查找**（ctrl+F）：打开该编辑器的搜索面板。
- 切换**自动保存**：开启时，更改按计划写入磁盘。关闭时，仅手动保存会写入，标签页或标题上的未保存更改标记会提醒你。

## 主页标签页

最左侧的主页标签页不可关闭。要从任意编辑器返回，点击该标签页或使用 文件 ▸ **返回主页**。
