# AI 助手面板

每个编辑器都能唤起 AI 面板：选中内容、下达指令，然后观看结果流式输出。

## 打开与使用

![Docs 中的 AI 面板](img/ai-panel.png)

- 入口：每个编辑器功能区中的 **AI 按钮**、上下文菜单中的 **询问 AI**，或标记栏上的询问 AI。
- 用自然语言说明任务（重写这段 / 把这一列变成百分比 / 重新排版这个页面……）然后按 Enter。
- 回答以**流式**渲染；当 AI 需要工具（读取文档、编辑文档）时会执行工具并持续到完成。
- **停止**：随时停止当前轮次。
- **队列**：回答流式输出时，按 Enter 会把消息放入队列而非直接发送——输入框上方的栏会统计它们；展开可编辑、删除、调整顺序、暂停或清空。当前轮次结束后下一条消息自动执行；Esc 仍会停止当前轮次。

## 它能做什么

- **Docs**：重写/扩写/翻译/摘要，插入表格和图片，调整格式；每轮之前都有快照。
- **Sheets**：公式、填充数据、批量修改、格式化。
- **Slides**：生成整套演示文稿、调整布局、重写文案。
- **PDF**：对选中的文本或页面进行问答和摘要。
- **Markdown / HTML**：重写、扩写、翻译。
- **主页 ▸ 询问 AI** 会基于你加星标的文件作答并引用它们——知识库面板在主页章节有自己的部分，Docs 的 AI 面板具备相同能力。

## 回退与安全

- Docs 的面板保留**版本列表**：每轮一个快照，可回退到任意一个，且该回退也能用 Ctrl+Z 撤销。重新打开文档后快照依然保留。
- AI 的编辑走与手动编辑相同的编辑流水线（可撤销、依赖保存）——任何改动都逃不过你的保存确认。

## 对 AI 隐藏选中内容

- Slides、HTML 和 Markdown 中可以把选中内容对模型隐藏：右键 ▸ **对 AI 隐藏选中内容**，给占位符命名，模型会读到 `{{名称}}` 代替它。（Markdown 通过其功能区上的闭眼开关启用；HTML 的选项位于源码面板中。）
- 文件保留真实文本——保存、导出和打印不受影响，重新打开后标记依然存在。同一菜单项可移除隐藏（Markdown 中有单独的 **重新向 AI 显示选中内容** 项）。
- HTML 会隐藏元素内容、属性值和脚本字符串；渲染后的页面永不改变。
- Slides 还会隐藏整张图片、视频和音频，含隐藏内容的幻灯片绝不会以截图形式发送：自动布局检查会跳过该页面并给出提示。
- 这仅适用于应用内的 AI——CLI、MCP 工具和无头导出会直接读取文件，仍能看到文本。

## 隐私

- 指令和相关文档内容会发送到**你配置的模型服务**（Genspark 托管或自定义端点，见下一章）；未配置则不会发送任何内容。
- 本地文件不会上传到任何地方；BYOK 密钥保存在本机应用设置文件中，仅在请求头中发送。
