# HTML 编辑器

HTML 编辑器以两种模式打开 .html 和 .htm 文件：**预览**用于显示渲染后的页面，**源码**用于编辑原始文本。

- **预览**：按页面实际显示效果呈现，样式表和相对图片从文件附近位置加载。
- **预览检查器**：单击选中元素，双击就地编辑文本，工具栏按钮可删除元素，Ask AI 可就当前选中内容提问。
- **源码模式**：直接编辑 HTML，ctrl+F 查找，Replace All 保存重写后的标记。
- **保存**逐字节保留原文件，包括 BOM、CRLF 和末尾换行。无改动保存不会重写文件。
- **缩放**：ctrl + 鼠标滚轮，或双指捏合，可改变预览缩放比例；预览中按 ctrl+Z 撤销上一次编辑。
- **对 AI 隐藏**：在源码模式下右键选中内容——元素内容、属性值、脚本字符串——模型看到的是占位符；翻译后的页面永不改变（详见 AI 面板章节）。

## 工具栏

在预览中单击任意元素，其上方会弹出工具栏：

![浮动在选中元素上方的工具栏](img/html-toolbar.png)

- **文件与历史**：保存、另存为、撤销、重做、查找，以及**自动保存**开关，定期将改动写入磁盘。
- **预览 / 源码**切换器在页面视图与代码之间切换，**演示**按钮全屏显示页面。
- **格式**包括加粗、斜体，以及放大和缩小字号的按钮。选中元素时可用**样式面板**，提供颜色等设置。
- **插入**可添加标题、段落、表格、通过链接插入图片及其他元素。
- 选中图片时的**图片操作**：裁剪、**移除背景**、替换图片、锁定宽高比。
- 在预览检查器中选中元素时的**元素操作**：删除、复制、上移或下移。
- **AI 按钮**打开 AI 面板，可直接就选中元素提问。

## 导出

文件菜单中的操作全部在本地完成，且都会询问保存位置：

- **导出为 Word…**和**导出为 PDF…**写出真正的 .docx 或 .pdf。
- **导出为单文件 HTML…**写出一个内嵌图片的 .html。它不会覆盖你当前打开的文件，并会告知有多少图片无法内嵌。

## 插入脚手架

对于空白页面，**插入 ▸ 插入脚手架**会按标准模式写入最小文档：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title></title>
  </head>
  <body></body>
</html>
```

每一部分都有其理由，正因如此它才是一条命令，而非需要手动输入的内容：

- **doctype**，否则预览会以怪异模式运行，导致盒模型尺寸和表格布局遵循与你预期不同的规则；
- **`lang`**，否则屏幕阅读器没有语言可用来朗读页面，浏览器会为错误的语言选择字体和拼写检查器；
- **charset**，否则包含非拉丁文本的页面可能被解码为乱码。

Meta viewport 有意不包含：此编辑器在桌面面板中显示，没有需要影响的移动端 viewport。

`lang` 跟随应用界面语言，因此你插入的脚手架正是你的工具已为其配置好的。之后你可以自由编辑。

该菜单项仅在编辑模式下、且文档为空时出现——一旦有内容，就没有可插入脚手架的_位置_了。
