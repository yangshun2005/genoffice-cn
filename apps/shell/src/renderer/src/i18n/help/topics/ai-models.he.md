# AI 模型与设置

## 提供商与模型

模型和密钥在设置中配置（首页左下角的账户栏）：

![设置窗口](img/settings-general.png)

- **Genspark 托管**：登录（设备码流程）后即可使用——无需任何配置。
- **自定义端点（BYOK）**：设置 ▸ AI 为每种协议配置 Base URL 和 API 密钥——OpenAI 兼容、Anthropic、Gemini、DeepSeek、DashScope（qwen）等。密钥保存在本机的应用配置文件中，仅在请求头中发送。Atlas Cloud 属于内置协议之一。
- 可为每种能力选择不同模型：对话/生成、图像生成、图像分析。
- **连接测试**：保存前验证端点可访问且模型可见。
- Base URL 也可包含路径和查询字符串（网关风格）；端点路径会正确拼接。

## CLI 集成（Codex 类型）

- 设置中可填写本地 CLI 程序路径（支持非 ASCII 字体下的主目录及 ~ 前缀；~ 会自动展开）；"模型检测"会检查该 CLI 有哪些可用模型。
- 校验仅检查是否存在——不限制字符集。

## 变更何时生效

- 模型和端点的变更立即生效；已进行中的对话继续使用旧配置，直到其下一轮。
