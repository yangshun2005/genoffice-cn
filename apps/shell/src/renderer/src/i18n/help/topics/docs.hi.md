# Docs：文字处理

Docs 是类似 Word 的处理器：读写真正的 .docx，分页是真正的所见即所得。

## 功能区

选项卡：**开始 / 插入 / 绘图 / 布局 / 设计 / 引用 / 审阅 / 视图**，以及选中对象时的上下文选项卡（表格设计和布局、图片、页眉和页脚）。Docs 的命令栏有自己的密度：**紧凑**（⌥⌘K / Ctrl+Alt+K）保留图标、去掉标签，该选择会被记住。

- **开始**：剪贴板；字体（含 CJK 字号和着重号）以及 **清除所有格式** 和 **显示/隐藏格式标记** 开关；段落（对齐/缩进/间距/列表）以及 **定义新项目符号 / 定义新编号格式 / 多级列表**，它们把你的列表样式保存到文档中；样式（标题 1-6/正文/引用，可修改）以及用于完整列表的 **样式窗格**。一个样式可以分别指定东亚字体和拉丁字体（例如 CJK 字体配 Times New Roman）；这一配对在 .docx 往返中保持不变。
- **插入**：分页符/分节符；表格（行 × 列网格，或用 **插入表格…** 指定精确尺寸）；图片、形状、文本框；来自现成库的 **封面** 和 **空白页**；**图表**；**首字下沉**；**艺术字**；域（日期、时间、页码、总页数、文件名）；超链接、**书签** 和交叉引用；批注；页眉和页脚以及页码；符号和公式。
  - **图表** 插入的是带自身数据的真实图表对象——柱状、折线或饼图——不是图片。Word 的 _编辑数据_ 会打开其背后的数字。
- **绘图**：在页面上书写墨迹，位于 **绘图工具** 组中——**选择** 返回文本编辑，然后是 **笔**、**荧光笔** 和 **橡皮擦**（一次点击或一次滑动删除整条线）。旁边是 **笔样式** / **荧光笔样式**，同一个控件，带一行颜色样本和粗细；其名称随当前工具变化。墨迹作为浮动在文本上方的批注保存到文档中，因此保存并重新打开后仍在，下一组的 **全部清除** 会将其彻底删除。
- **布局**：页边距、方向和纸张大小、分栏、段落缩进和间距。
- **设计**：主题、颜色集、水印、页面边框。
- **引用**：目录（可更新）、脚注/尾注、题注、交叉引用。

  ![引用选项卡](img/docs-references.png)

- **审阅**：**编辑器** 检查整个文档的拼写、语法和标点；**翻译**；拼写检查；批注（**AI 处理批注** 对打开的批注生效）；修订，带所有标记/简单标记视图、接受/拒绝，以及 **AI 修订摘要**；字数统计；与另一文件 **比较**；**保护文档**。
- **视图**：查看文件的五种方式——**打印布局**、**Web 布局**、**大纲**、**阅读模式** 和 **页面预览**；小/大/百分比/页宽/单页；**AI 面板**；**深色模式**；标尺、网格线和导航窗格；**新建选项卡**、**拆分** 和 **切换选项卡**；以及可搜索的 **键盘快捷键** 对话框。
  - **深色模式** 使页面及其周围的画布变暗，从不影响功能区——这是 Word 在深色编辑页面和深色窗口之间的划分。该选择会被记住，并在任何情况下优先于应用主题。
  - **拆分** 在下方打开第二个窗格，独立滚动并显示前一个的副本；用其边缘的 × 关闭它。

## 导航窗格

**视图 ▸ 导航窗格** 打开一个侧边窗格，包含文档的标题大纲、覆盖整个文档的搜索框，以及每一页的缩略图。它是否打开会在启动之间记住，因此你通过大纲浏览的文档始终可导航。

**大纲** 是标题树。在大纲中右键单击某个标题，可以折叠它或改变结构，而不仅仅是导航：

- 对某个标题 **折叠 / 展开** 会折叠其整个子树——章节消失，但其文本仍留在文档中。
- **全部折叠 / 全部展开** 一次性折叠或展开整棵树。在长报告中，这就是可读大纲和一堵文字墙之间的区别。
- **显示标题级别** 把树过滤到你关心的深度，这样 _显示标题 1_ 就给你一份一眼可览的目录。
- **提升级别 / 降低级别** 改变标题的级别，其下每个标题继承的级别也随之改变——章节就这样变成小节。
- **上方新建标题 / 下方新建标题** 在光标处插入标题，无需离开窗格。
- **删除** 删除标题 _及其下方的一切_，这正是要小心的地方：这是删除子树，不是删除一行。
- **选择标题和内容** 从标题选到其子树末尾，便于编辑整个小节。

## 右键菜单

在主体中任意位置右键单击——菜单随点击对象而变化。主要分组：

- **剪贴板**：剪切 / 复制 / 粘贴 / **以纯文本粘贴**。
- **字体、段落**：无需前往功能区即可更换字体、改变字号、加粗/斜体/下划线、对齐/缩进/间距。
- **同义词**：显示所选单词的同义词；点击其一进行替换。
- **翻译**（AI）：通过 AI 面板将所选内容翻译为目标语言（英语、简体中文、日语、韩语、法语、德语、西班牙语……）。
- **新建批注**：在所选内容上添加批注。
- **拼写**（在拼错的单词上）：建议选项、全部忽略、添加到词典、设置校对语言。
- **超链接**：打开 / 编辑 / 复制链接 / 删除超链接。
- **图片**：查看图像、保存图像、**文字环绕**（嵌入型 / 四周型 / 上下型 / 衬于文字下方 / 浮于文字上方）、排列顺序。
- **域**（目录、页码）：更新域 / 显示域代码 / 编辑域。
- **列表编号**（在列表内）：重新开始编号 / 继续编号 / 更改列表级别 / 设置编号值。
- **表格**（光标在表格中）：插入行/列、合并 / 拆分单元格、拆分表格、自动调整、单元格对齐、平均分布行/列、表格属性、删除菜单、选择。

## 编辑

- 查找和替换（ctrl+F / ctrl+H）：区分大小写、全字匹配、正则表达式。
- 格式刷；深度撤销/重做；粘贴选项。
- 表格：合并/拆分单元格、行和列操作、边框和底纹、排序、公式。行在需要处跨页断开，单元格内 Ctrl+Enter 正好在那里分页——打印和 PDF 也是如此。
- 图片：文字环绕、裁剪、压缩；绘图画布。

## CJK 排版

- 标点压缩和禁则换行与 Word 一致；全角-半角转换。
- 字体候选覆盖 Windows 和 macOS 常见 CJK 家族名称。

## AI

- 功能区的 AI 按钮和侧边面板：重写、扩写、翻译、摘要、含表格的预设，以及自由书写的指令。
- 每个 AI 轮次前都会拍摄快照；从版本列表回退，该回退也可撤销。

## 保存和导出

- 保存 .docx 时只重写更改过的段落——未改动的内容逐字节保持相同。
- 导出 PDF（按当前分页）和逐页图片。

## 打印

通过系统对话框 ctrl+P，页面所见即所得。
