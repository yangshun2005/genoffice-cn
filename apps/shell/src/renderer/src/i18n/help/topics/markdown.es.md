# Markdown 编辑器

Markdown 编辑器打开 .md / .markdown —— 以及 .txt / .json，直接进入代码视图 —— 提供代码加渲染预览。

- **打开**：从主页或 文件 ▸ 打开；命令行也可以。
- **编辑**：纯文本编辑；GFM 扩展（表格、任务列表、删除线、自动链接）会在预览中渲染。
- **预览**：实时；图片等相对资源在文档旁解析。
- **保存**：逐字节忠实：BOM、CRLF 和末尾换行符的存在与否都会保留；无改动的保存不会重写文件。
- **查找与替换**：Ctrl+F 在源代码中查找；全部替换会重写内容。
- **AI**：几个预设按钮让助手重写、扩写或翻译文档。选中内容可以对 AI 隐藏（见 AI 面板章节）。

## 工具栏

编辑器上方的一行按钮（悬停查看说明）：

![Markdown 工具栏](img/md-toolbar.png)

- **文件与历史**：保存、另存为、撤销、重做、查找；右侧的**自动保存**开关会按间隔将改动写入磁盘。
- **AI 按钮**：打开 AI 面板；旁边是重写、扩写和翻译预设。
- **段落样式**（下拉）：在正文和标题级别之间切换。
- **行内格式**：**粗体**、_斜体_、~~删除线~~、`行内代码`、链接。
- **列表**：无序列表、有序列表、任务列表。
- **插入**：表格、图片、分隔线。
- **属性**：在文件开头插入 YAML front matter 块，或跳转到该处。
- **大纲**：按标题层级跳转。
- **拼写检查**：开启或关闭本文档的拼写检查。
- **图床设置**：粘贴或拖入的图片优先上传到你自己的存储 —— 兼容 S3（R2/OSS/COS/MinIO）、SM.MS 或 GitHub —— 以本地 assets 副本作为兜底。

三个快速示例：

- **标题**：将光标放在该行 ▸ 段落样式下拉 ▸「标题 1」。
- **表格**：点击**插入表格** ▸ 拖动行列数 ▸ 在单元格中输入；预览立即渲染。
- **任务列表**：选中几行 ▸ 点击**任务列表** ▸ 每行变为 `- [ ]`，在预览中显示为复选框。

## 导出

文件菜单，全部本地处理，全部会询问输出位置：

- **导出为 Word…** 和 **导出为 PDF…** 写出真正的 .docx 或 .pdf。
- **导出为图片…** 在你选择的文件夹中每页写出一张 PNG。
- **转换并在 Docs 中打开** 转换为 .docx 并在应用内的 Docs 标签页中打开：不是转交给任何云端服务，转换后的副本存放在缓存文件夹中，大约一周后清理。

## 源代码视图

功能区带有一个**源代码**开关（随应用一同本地化）。开启后，编辑器被原始 Markdown 取代：正是保存时写入的文本，没有任何美化，没有任何底层规范化。

- **编辑逐字节忠实。** 从源代码视图保存产生的字节与从编辑器保存相同：BOM、CRLF 和末尾换行符的存在与否都会保留。
- **是同一个文档。** 在编辑器和源代码之间随意切换；源代码就是编辑器自身的文本，不是需要合并的副本。
- **此视图打开时格式工具栏不可用**，因为那些按钮大多插入只在渲染部分才有意义的编辑器构造。关闭视图后它会重新出现。
- **.txt 和 .json** 直接在此以代码视图打开：没有什么可渲染的，所以代码_就是_文档。
