# 标签页与窗口管理

所有打开的文件都在同一个窗口里，顶部的标签栏在它们之间切换——就像浏览器一样。

![标签栏：“主页”和两个文档](img/tabs.png)

## 基础操作

- **切换**：点击标签，或在标签栏上滚动鼠标滚轮，即可循环翻页。
- **关闭**：标签上的 × 图标，或 ⌘W/ctrl+W。有未保存的更改时会先询问。
- **新建**：标签栏右端的 + 图标。
- **即时激活**：按下标签时立即切换，无需等点击结束。

## 重命名：双击标签

**双击任意文件标签**，其标题会就地变成输入框：Enter 确认，Escape 取消，失焦也确认；此时确认 IME 候选词的 Enter 不会被当作确认。重命名会经过与“主页”中重命名行相同的安全检查（非法字符、重名），会修改磁盘上的文件名并更新最近列表。

## 拖拽调整顺序

按住标签向两侧拖动即可调整顺序：相邻标签会立即让位，松开时顺序固定。4 像素的“死区”可防止普通点击移动标签。

## 上下文菜单

右键点击标签可看到：**在新窗口中打开**——每个可分离的文档标签都可用——以及**关闭**，在不可关闭的标签上处于禁用状态。两个菜单项都会随应用语言一起翻译。

## 分离为独立窗口

**将标签拖出标签栏**（或使用“在新窗口中打开”命令），它就会变成一个拥有实时文档的独立窗口；再拖回来即可放回标签栏。分离出的窗口是完全平等的参与者：可以在那里继续编辑和保存。

## 所有标签的列表

当标签多到标签栏放不下时，标签栏右端的小图标会打开完整列表（系统菜单，内容区域永远不会遮挡它）；用方向键选择。

## 每个编辑器内的工具栏

每个编辑器标签顶部都有一排工具（具体布局因编辑器略有不同）：

- **保存**（⌘S/ctrl+S）和**另存为…**。
- **撤销 / 重做**：多级；每个编辑器维护自己的历史。
- **查找**（ctrl+F）：打开该编辑器的搜索面板。
- **自动保存**开关：开启时，更改会按计划写入磁盘；关闭时，仅在手动保存时写入（标签或标题上的未保存更改标记会提醒这一点）。

## “主页”标签

最左侧的“主页”标签无法关闭；要从任意编辑器返回，点击它或使用 文件 ▸ **返回主页**。
