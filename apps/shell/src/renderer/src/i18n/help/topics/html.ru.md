# HTML 编辑器

HTML 编辑器以两种模式打开 .html / .htm 文件：**预览**（渲染后的页面）和**源码**。

- **预览**：真实渲染；相对样式表和图片从文件所在目录加载。
- **预览检查器**：单击选中元素，双击就地编辑其文本，通过工具栏删除，并就选中内容询问 AI。
- **源码模式**：编辑 HTML；ctrl+F 搜索，"替换"会保存重写后的标记。
- **保存**：逐字节精确（BOM/CRLF/末尾换行均保留）；无改动保存不会重写任何内容。
- **缩放**：ctrl+滚轮或捏合手势缩放预览；预览内 ctrl+Z 撤销上一次编辑。
- **对 AI 隐藏**：在源码模式下右键选中内容——元素内容、属性值、脚本行——模型只能看到占位符；渲染后的页面不变（详见 AI 面板章节）。

## 工具栏

在预览中单击任意元素，其上方会出现工具栏：

![选中元素上方的浮动工具栏](img/html-toolbar.png)

- **文件与历史**：保存、另存为…、撤销、重做、查找；**自动保存**开关按计划写入更改。
- **预览 / 源码**切换开关；**显示**全屏打开页面。
- **格式**：加粗、斜体、增大和减小字号；针对选中元素的**样式面板**（颜色等）。
- **插入**：标题、段落、表格、图片（通过链接）、更多。
- **图片操作**（选中图片时）：裁剪、**移除背景**、替换、保持比例。
- **元素操作**（在预览检查器中选中时）：删除、复制、上移和下移。
- **AI 按钮**：打开 AI 面板；可直接从那里询问选中的元素。

## 导出

"文件"菜单：全部在本地运行，且都会询问结果保存位置：

- **导出为 Word…** 和 **导出为 PDF…** 写入真正的 .docx 或 .pdf。
- **导出为单个 HTML 文件…** 写入一个内嵌图片的 .html。它不会覆盖你当前打开的文件，并会告知有多少图片未能内嵌。

## 插入骨架

对于空白页面，**插入 ▸ 插入骨架**命令会写入标准模式下的最小文档：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title></title>
  </head>
  <body></body>
</html>
```

这里的每一部分都有其理由——所以它是一条命令，而不是需要手打的内容：

- **doctype**——否则预览会以 quirks mode 运行，其中块级尺寸和表格布局遵循与你预期不同的规则；
- **`lang`**——否则屏幕阅读器不知道用哪种语言朗读页面，浏览器也会为错误的语言选择字体和拼写检查；
- **charset**——否则含非拉丁文本的页面可能变成无法阅读的乱码（mojibake）。

viewport 元标签有意缺失：这是在桌面面板中渲染，移动端 viewport 无从发挥作用。

`lang` 跟随应用界面语言，因此插入的骨架正好与你的工具已配置的一致。之后可随意编辑。

该菜单项仅在编辑模式下、且文档为空时出现：一旦有了内容，就再没有_地方_可插入骨架了。
