# 设置、语言、主题与 MCP 集成

## 打开设置

主页左下角的账户行可打开设置面板（未登录时显示为登录）。面板包含六个部分：账户、AI 模型、媒体与 AI 搜索、通用、集成和信息。

![设置 ▸ 通用，可在此设置语言、主题、自动保存和使用统计开关](img/settings-general.png)

模型配置有专门的文章；在 **媒体与 AI 搜索** 中，你可以为每个提供商启用图像生成、图像分析、视频分析、网页搜索和本地文件搜索。

## 语言

- 设置提供 **21 种界面语言**：英语、简体中文、日语、韩语、法语、德语、西班牙语、泰语、印尼语、俄语、阿拉伯语、葡萄牙语、意大利语、波兰语、捷克语、荷兰语、马来语、希伯来语、印地语、繁体中文、越南语。
- 切换立即生效并被记住；原生菜单栏会以新语言重建。

## 主题

浅色 / 深色 / 跟随系统。跟随系统选项会跟随操作系统的外观，编辑器同步适配，无闪烁。

## 通用

- **发送匿名使用统计** — 默认开启。使用 Google Analytics 4，发送你的公网 IP 和传输元数据；文档内容和文件名绝不会被收集，每个事件只携带一个类型，如「打开了一个 .docx」。你可以随时在此关闭。
- **AI 侧边栏位置**（左侧或右侧）、**AI 面板文字大小** 和 **AI 聊天中的拼写检查**。
- **在新文档中打开 AI 面板** — 关闭时，新文档打开时面板处于收起状态，一键即可展开。
- **自动保存所有文档** 会在每个编辑器中默认开启自动保存；你仍可为单个窗口关闭。
- **保存位置** 配有 **更改** 按钮，以及 **Office 文档默认应用**，用于让 GenOffice 处理 .docx / .xlsx / .pptx。

## 媒体与 AI 搜索

它们不是开关：每项能力选择为其服务的提供商，提供商的密钥和基础 URL 只需填写一次并共享：

- **网页搜索**、**图像生成**、**图像分析** 和 **视频分析**，各自配有提供商、模型、密钥和基础 URL。
- **本地文件搜索** 在本机运行。下方，**Jev 搜索重排序** 默认 **关闭**。开启后，前 20 条本地结果的摘录——每份文档最多 1,200 个字符，加上文件名和文件夹名——会发送到所选的决策端点（通过 OpenRouter 或 TypeSafe 的 Jev、Perplexity、Liquid AI d1、Cloudflare、本地引擎或自定义 URL）按相关性重新排序。关闭时，任何数据都不会离开设备。

## 信息

- **版本**、项目的 GitHub 链接和 **在 GitHub 上加星** 按钮。
- **更新通道**：稳定版或 Beta。修改立即生效并控制更新检查；不会将 Beta 安装回退到稳定版。

## 关联为默认应用

设置可将 GenOffice 注册为 .docx / .xlsx / .pptx / .pdf 等文件的处理程序（系统级默认应用注册；需要时确认）。

## Genspark 登录

- 登录入口（在设置或云项目列表中）使用 **设备码** 流程：GenOffice 显示一个代码并在浏览器中打开登录页面；完成后操作自动继续。
- 登录仅用于：云项目列表和 Genspark 托管的模型。不登录时，所有本地功能和自定义模型仍可正常使用。
- 在设置中一键退出登录。

## MCP 集成（面向高级用户 / AI 客户端）

**集成** 是将 GenOffice 连接到编程代理的面板，有专门的文章：连接编程代理。简而言之——选择一条路径（命令行或 MCP），按照对应章节操作，然后打开新对话并提问。

![设置 ▸ 集成：三个步骤，然后是技能行和 MCP 选项](img/settings-integrations.png)

在 **本地 HTTP 服务器** 下，应用也可自行运行服务器——一个启用开关和一个端口——**高级** 会添加健康检查 URL 和日志文件，而不用交给助手。仅监听 localhost。

## 命令快速摘要

| 命令               | 作用               |
| ------------------ | ------------------ |
| `genoffice <file>` | 打开文件           |
| `genoffice mcp`    | 启动本地 MCP 服务器 |
| `genoffice --help` | 所有命令和选项     |
