# 标签页与窗口管理

所有打开的文件共用同一个窗口。顶部的标签栏用于在文件之间切换，就像浏览器一样。

![标签栏：首页和另外两个文档](img/tabs.png)

## 基本操作

- **切换标签页**：点击标签页，或在标签栏上滚动鼠标滚轮逐个切换。
- **关闭标签页**：按标签页上的 ×，或按 ⌘W/ctrl+W。若有未保存的修改，系统会先询问。
- **新建标签页**：按标签栏右端的 +。
- **即时激活**：按下标签页即立即切换，无需等点击动作完成。

## 重命名：双击标签页

**双击任意文件标签页**，名称会变为内联文本输入框：Enter 确认，Esc 取消，点击框外也会确认，而输入法选字用的 Enter 不会被误判为确认。此重命名经过与首页行内重命名相同的安全校验（禁用字符、重名），随后在磁盘上重命名文件并刷新最新文件列表。

## 拖动排序

按住标签页向两侧拖动即可重新排序。相邻标签页会即时让位，松开鼠标后顺序落定。4 像素的死区让普通点击不会使标签页抖动。

## 右键菜单

右键点击标签页可选择 **在新窗口中打开**（在所有可拖出的文档标签页上显示）和 **关闭**（该标签页无法关闭时置灰）。两项均为应用语言。

## 拖出为独立窗口

**将标签页拖出标签栏**（或使用 在新窗口中打开 命令），该标签页会变成自己的窗口，文档仍处于编辑状态。拖回来即可重新进入标签栏。拖出的窗口是完整的对比窗口，你仍可在其中正常编辑和保存。

## 列表 全部标签页

当标签页溢出标签栏时，标签栏右端的小标签页图标会打开完整列表（系统菜单，不会被内容区域遮挡）。用方向键选择。

## 各编辑器的内置工具栏

每个编辑器的标签页顶部都有工具栏（各编辑器的布局细节略有不同）：

- **保存**（⌘S/ctrl+S）和 **另存为…**
- **撤销 / 重做**：可多级回退，每个编辑器保存自己的历史。
- **查找**（ctrl+F）：打开该编辑器的查找面板。
- **自动保存** 开关：开启时，更改会按设定时间写入磁盘；关闭时，仅在手动保存时才写入（标签页或标题上的未保存标记会提醒你）。

## 首页标签页

最左侧的首页标签页无法关闭。若要从任意编辑器返回，点击该标签页，或使用菜单 文件 ▸ **返回首页**。
