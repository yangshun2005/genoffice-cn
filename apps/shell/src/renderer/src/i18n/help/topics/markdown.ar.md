# Markdown 编辑器

Markdown 编辑器打开 `.md` / `.markdown` 文件——`.txt` / `.json` 则直接以源码视图打开——提供源码加预览的编辑体验。

- **打开**：从主页或菜单 文件 ▸ 打开…；也可通过命令行。
- **编辑**：纯文本编辑；预览中显示 GFM 扩展（表格、任务列表、删除线、自动链接）。
- **预览**：实时；图片等相对资源按文档所在位置解析。
- **保存**：字节级忠实——BOM、CRLF、文件末尾换行均保留；未修改时保存不会重写文件。
- **查找与替换**：ctrl+F 在源码中查找；「替换」会重写结果。
- **AI**：预设按钮让助手重写、扩写或翻译文档。可隐藏 AI 选区（见 AI 面板章节）。

## 工具栏

编辑器顶部一行按钮（悬停查看提示）：

![Markdown 工具栏](img/md-toolbar.png)

- **文件与历史**：保存、另存为…、撤销、重做、查找；右侧的**自动保存**开关会定期将更改写入磁盘。
- **AI 按钮**：打开 AI 面板；旁边是重写、扩写、翻译选项。
- **段落样式**（下拉菜单）：在正文与各级标题间切换。
- **行内格式**：**粗体**、_斜体_、~~删除线~~、`行内代码`、链接。
- **列表**：无序列表、有序列表、任务列表。
- **插入**：表格、图片、水平分割线。
- **属性**：在文件顶部插入或跳转到 YAML front matter 块。
- **大纲**：按标题层级跳转。
- **拼写检查**：开启或关闭本文档的拼写检查。
- **图床设置**：粘贴和拖入的图片先进入你自己的存储——兼容 S3（R2/OSS/COS/MinIO）、SM.MS 或 GitHub——本地副本保留在 assets 作为备份。

三个快速示例：

- **标题**：将光标置于某行 ▸ 段落样式菜单 ▸「标题 1」。
- **表格**：点击**插入表格** ▸ 拖动选择行列数 ▸ 在单元格中输入；预览立即显示。
- **任务列表**：选中几行 ▸ 点击**任务列表** ▸ 每行变为 `- [ ]`，预览中显示为复选框。

## 导出

文件菜单，全部本地处理，全部会询问结果保存位置：

- **导出为 Word…** 和**导出为 PDF…** 生成真正的 .docx 或 .pdf 文件。
- **导出为图片…** 在你选择的文件夹中为每页生成一个 PNG 文件。
- **转换并在 Docs 中打开**将文档转换为 .docx 并在应用内嵌的 Docs 标签页中打开——这不是云端引用，转换后的副本保存在临时文件夹中，约一周后清理。

## 源码视图

工具栏带有**源码**开关（随应用语言本地化）。开启后以原始 Markdown 取代编辑器：正是保存操作所写入的文本，无美化，无底层规范化。

- **字节级忠实编辑。** 从源码视图保存产生的字节与从编辑器保存完全相同——BOM、CRLF、末尾换行全部保留。
- **就是同一个文档。** 可自由切换两种视图；源码就是编辑器自身的文本，不是需要合并的副本。
- **格式工具栏不可用**，因为其中大多数按钮插入的是编辑器专有结构，仅在渲染侧有意义。关闭源码视图后恢复。
- **`.txt` 和 `.json`** 直接在此以源码视图打开：没有渲染，源码_就是_文档。
