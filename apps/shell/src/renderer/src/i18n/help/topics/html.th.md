# HTML 编辑器

HTML 编辑器以两种模式打开 .html / .htm 文件：**预览**（渲染后的页面）和**源码**。

- **预览**：真实渲染，相对引用的样式表和图片从文件旁边加载
- **预览中的检查器**：单击选中元素，双击就地编辑其文本，从工具栏删除，以及对选中内容询问 AI
- **源码模式**：编辑 HTML，ctrl+F 查找，全部替换会将重写的标记保存到文件
- **保存**：保持文件字节级一致（BOM/CRLF/文件末尾换行均保留），未做任何修改的保存不会重写文件
- **缩放**：ctrl+滚轮 / 双指捏合调整预览大小，预览中 ctrl+Z 撤销最近的编辑
- **对 AI 隐藏**：在源码模式下右键选中部分——元素内容、属性值、脚本字符串——模型看到的是占位符，渲染页面不变（详见 AI 面板章节）

## 工具栏

在预览中单击任意元素，工具栏会浮现在它上方：

![浮现在选中元素上方的工具栏](img/html-toolbar.png)

- **文件与历史**：保存、另存为…、撤销、重做、查找。**自动保存**开关按设定时间写入更改
- **预览 / 源码**切换开关，以及**演示**以全屏显示页面
- **格式**：加粗、斜体、增大/减小字号，以及针对选中元素的**样式面板**（颜色等）
- **插入**：标题、段落、表格、图片（来自链接）、更多
- **图片操作**（选中图片时）：裁剪、**移除背景**、替换、锁定比例
- **元素操作**（在检查器中选中元素时）：删除、创建副本、上移/下移
- **AI 按钮**：打开 AI 面板并立即询问选中元素

## 导出

文件菜单全部在本地运行，且都会询问将结果保存到哪里：

- **导出为 Word…** 和 **导出为 PDF…** 会写入真正的 .docx 或 .pdf 文件
- **导出为单个 HTML 文件…** 会写入一个内嵌图片的 .html 文件，不会覆盖你正在打开的文件，并会告知有多少张图片无法内嵌

## 插入基本结构

如果页面为空，**插入 ▸ 插入基本结构**菜单会写入一份最小化的标准文档：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title></title>
  </head>
  <body></body>
</html>
```

每一部分都有其理由。这就是它是一条命令、而非需要你手动输入的原因：

- **doctype**：否则预览会在怪异模式下运行，盒模型和表格布局将使用与你预期不同的一套规则
- **`lang`**：否则屏幕阅读器没有语言可用来朗读此页面，浏览器会按错误的语言选择字体和拼写检查器
- **charset**：否则含非拉丁文本的页面可能显示为乱码（mojibake）

有意不包含 viewport 元标签，因为这是在桌面窗口中渲染，没有移动端 viewport 会影响它

`lang` 会跟随应用的界面语言，因此你插入的结构已按你的工具设置配置好。之后可随意继续编辑
