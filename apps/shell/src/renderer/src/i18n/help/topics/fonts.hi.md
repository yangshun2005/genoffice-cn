# 字体：系统字体与可下载字体家族

## 字体列表

字体控件位于每个编辑器的“开始”选项卡上（下图：Slides 中的字体组）：

![Slides 功能区中的字体组](img/fonts.png)

每个编辑器的字体选择器都会合并：本地已安装字体 + 平台常见候选字体（包括 Windows 和 macOS 常见的西文与 CJK 字体家族，以及 CJK 字体在其各自系统上的本地名称）。当系统能报告本地字体时，列表按实际存在的字体分组；否则回退到完整候选列表。

## 可下载字体（Slides）

- Slides 的字体选择器会打开**字体目录**：一个精选的 OFL 字体集合，覆盖多种文字；每个家族都包含常规和粗体字重。
- 选中后即从 CDN 下载（以校验和固定）并安装到应用的字体存储中——此后对每个文档可用，无需系统级安装。
- 安装内容保存在应用私有目录中，并随应用一同消失。

## CJK 排版

- Docs 中的 CJK 字体支持 Word 兼容的标点压缩和禁则换行规则（参见 Docs 章节）。
- 目录中的 CJK 家族以衬线和无衬线两种形式覆盖简体中文、繁体中文、日文和韩文。

## 管理本地字体

- “安装本地字体文件”入口会将磁盘上的 .ttf/.otf 文件加载到应用的字体存储中。
- 存储按家族归档；同一家族的多个字重可以共存。
