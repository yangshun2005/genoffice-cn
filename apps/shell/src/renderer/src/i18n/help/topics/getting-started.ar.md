# 快速开始：界面与基础

GenOffice 是一套完全在本地运行的办公套件：一个窗口、一行标签页，容纳六个编辑器——Docs（文字处理）、Sheets（电子表格）、Slides（演示文稿）、PDF、Markdown 和 HTML。文件是真正的 .docx / .xlsx / .pptx / .pdf 文件，与 Word、Excel、PowerPoint 完全兼容。无需任何网络连接。

## 界面概览

![主屏幕](img/home-screen.png)

窗口由三部分组成：

- **标签栏（顶部）**：每个打开的文件都是一个标签页。最左侧的主标签页始终存在，无法关闭；其余标签页是你的文档。双击任意标签页可就地重命名其文件。
- **内容区**：当前活动标签页的编辑器（或主屏幕）。
- **菜单栏**：macOS 上位于系统菜单栏，Windows/Linux 上位于窗口顶部。文件/编辑/视图菜单会随活动编辑器切换。

## 创建文档

以下任一方式：

- 在**主屏幕**的[快速开始](help://getting-started)区域点击快速创建卡片（AI Docs、AI Sheets、AI Slides……）。
- **文件 ▸ 新建**菜单：Docs（⌘N/ctrl+N）、Sheets、Slides、Markdown、HTML 或 PDF。
- 将文件拖入窗口，或在文件管理器中双击（若 GenOffice 是默认应用）。

新文档以无标题状态打开；首次保存时才在磁盘上创建文件。

## 打开文件

- **文件 ▸ 打开…**（⌘O/ctrl+O）打开系统文件选择器：.docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html。
- 点击主屏幕**最近使用**列表中的任意一项。
- 终端命令 `genoffice <file>` 也可打开文件。

## 保存模型

- **手动保存**：⌘S/ctrl+S，或文件 ▸ 保存 / 另存为…。首次保存时应用会询问位置和名称。
- **自动保存**仅在文件至少手动保存过一次后才启用——只读的 PDF 不会被静默重写。自动保存会在内容变更后不久触发。
- 关闭有未保存更改的标签页时，会先提示保存 / 忽略 / 取消。
- 所有写入都是原子的（临时文件 + 重命名），因此断电不会留下写了一半的文件。

## 常用快捷键

| 操作           | macOS | Windows / Linux |
| -------------- | ----- | --------------- |
| 新建文档       | ⌘N    | ctrl+N          |
| 打开           | ⌘O    | ctrl+O          |
| 保存           | ⌘S    | ctrl+S          |
| 关闭标签页     | ⌘W    | ctrl+W          |
| 打开此目录     | F1    | F1              |
| 折叠功能区     | ⌥⌘R   | Ctrl+F1         |

**折叠功能区**在所有编辑器中可用。标签栏保持不变，其下方的命令栏消失；当前选中的标签页同时充当折叠按钮，因此功能区折叠时没有选中的标签页，点击任意标签页即可重新显示功能区。双击标签页效果相同。折叠方向按编辑器分别记忆。Docs 增加了中等密度：**⌥⌘K** / Ctrl+Alt+K 将功能区收缩为仅图标，该选择同样会被记忆。

各编辑器专属的快捷键（格式刷、查找替换、表格操作……）在其各自章节中说明；Docs 还提供可搜索的「键盘快捷键」窗口（**⌘/**）（见其章节）。

## Option+Command 快捷键

Option+Command 是 Word 留给结构化跳转的层级，GenOffice 以同样方式填充它。Docs 占用大部分，Sheets 为匹配 Excel 占用两个专属快捷键，另有一个快捷键在所有编辑器中生效。

**Docs**

| 快捷键（macOS）  | 作用         | Windows / Linux    |
| ---------------- | ------------ | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3  | 标题 1 / 2 / 3 | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0              | 正文         | Ctrl+Alt+0         |
| ⌥⌘M              | 段落         | Ctrl+Alt+M         |
| ⌥⌘A              | 新建批注     | Ctrl+Alt+A         |
| ⌥⌘F              | 插入脚注     | Ctrl+Alt+F         |
| ⌥⌘E              | 插入尾注     | Ctrl+Alt+D         |
| ⌥⌘G              | 转到         | Ctrl+G             |

其中两个快捷键在 Windows 上不同，原因与 Word 区分它们的原因相同。**macOS 拥有 ⌥⌘D**——它用于显示和隐藏 Dock——因此插入尾注在 Mac 上是 ⌥⌘E，在其他所有平台上是 Ctrl+Alt+D。而**转到**放弃了 Alt：Ctrl+G，而 Mac 快捷键保留该键。

**Sheets**（焦点在网格上时）

| 快捷键（macOS）  | 作用     | Windows / Linux |
| ---------------- | -------- | --------------- |
| ⌥⌘0              | 外边框   | Ctrl+Shift+7    |
| ⌥⌘−              | 无边框   | Ctrl+Shift+−    |

Windows 不是 Mac 按键组合的改写。Excel for Mac 给 Sheets **两者**——⌘⇧7 和 ⌥⌘0 都是外边框的快捷键——因此在 Windows 上该命令保留其原有的 Ctrl+Shift 位置，只是 Option 层级不存在。

注意 **⌥⌘0 在 Docs 中表示「正文」，在 Sheets 中表示「外边框」**。两者从不在同一编辑器中同时出现，因此使用中不会冲突，但 ⌥⌘0 已被占用，不能用作全局快捷键。

**所有编辑器**：**⌥⌘R / Ctrl+F1** 折叠功能区，如上所述。

这也让 ⌥⌘D 在 macOS 上可供 GenOffice 使用，以备将来某条命令需要。
