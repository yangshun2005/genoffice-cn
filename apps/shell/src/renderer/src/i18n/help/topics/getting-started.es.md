# 快速开始：界面与基础

GenOffice 是一套完全在您本机运行的办公套件：一个窗口、一行标签页，内含六个编辑器：Docs（文字处理）、Sheets（电子表格）、Slides（演示文稿）、PDF、Markdown 和 HTML。文件是真正的 .docx / .xlsx / .pptx / .pdf，可与 Word、Excel 和 PowerPoint 完全互换。无需网络。

## 界面说明

![启动屏幕](img/home-screen.png)

窗口分为三部分：

- **标签栏（顶部）**：每个打开的文件是一个标签页。最左侧的“主页”标签始终存在且无法关闭；其余标签页就是您的文档。双击标签页可就地重命名文件。
- **内容区**：当前活动标签页对应的编辑器（或启动屏幕）。
- **菜单**：macOS 上位于系统菜单栏，Windows/Linux 上位于窗口顶部。文件/编辑/视图菜单会随当前编辑器变化。

## 创建文档

以下任一方式均可：

- 点击**主页**中[快速开始](help://getting-started)区域的快速创建卡片（AI Docs、AI Sheets、AI Slides……）。
- **文件 ▸ 新建**菜单：Docs（⌘N/ctrl+N）、Sheets、Slides、Markdown、HTML 或 PDF。
- 将文件拖入窗口，或在文件管理器中双击该文件（前提是 GenOffice 为默认应用）。

新文档打开时无标题；只有首次保存时才会在磁盘上创建文件。

## 打开文件

- **文件 ▸ 打开**菜单（⌘O/ctrl+O）打开系统选择器：.docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html。
- 点击启动屏幕**最近使用**列表中的任意一项。
- 在终端中执行 `genoffice <file>` 也可打开文件。

## 保存模型

- **手动保存**：⌘S/ctrl+S，或文件 ▸ 保存 / 另存为。首次保存会询问位置和名称。
- **自动保存**仅在文件至少手动保存过一次后才启用：只读的 PDF 绝不会被偷偷改写。内容变更后不久即触发自动保存。
- 关闭有未保存更改的标签页时，会先询问保存 / 放弃 / 取消。
- 每次写入都是原子的（临时文件加重命名），因此断电也不会留下半成品文件。

## 常用快捷键

| 操作         | macOS | Windows / Linux |
| ------------ | ----- | --------------- |
| 新建文档     | ⌘N    | ctrl+N          |
| 打开         | ⌘O    | ctrl+O          |
| 保存         | ⌘S    | ctrl+S          |
| 关闭标签页   | ⌘W    | ctrl+W          |
| 打开本手册   | F1    | F1              |
| 折叠功能区   | ⌥⌘R   | Ctrl+F1         |

**折叠功能区**在所有编辑器中均可用。标签栏保留，下方的命令带隐藏；当前选中的标签页兼作折叠控件，因此功能区折叠时没有标签页处于选中状态，点击任意标签页即可重新显示命令带。双击标签页效果相同。折叠状态按编辑器分别记忆。Docs 还增加了一档中间密度：**⌥⌘K** / Ctrl+Alt+K 将命令带压缩为仅图标，同样会被记忆。

各编辑器内部的快捷键（格式刷、查找替换、表格操作……）见各自章节；Docs 还提供可搜索的键盘快捷键对话框（**⌘/**）（参见其章节）。

## Option+Command 快捷键

Option+Command 是 Word 为结构化跳转保留的层级，GenOffice 同样将其填满。Docs 占据大部分；Sheets 取用其中两个以对齐 Excel；有一个快捷键在所有地方都可用。

**Docs**

| 快捷键（macOS） | 作用         | Windows / Linux    |
| --------------- | ------------ | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | 标题 1 / 2 / 3 | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0             | 正文         | Ctrl+Alt+0         |
| ⌥⌘M             | 段落         | Ctrl+Alt+M         |
| ⌥⌘A             | 新建批注     | Ctrl+Alt+A         |
| ⌥⌘F             | 插入脚注     | Ctrl+Alt+F         |
| ⌥⌘E             | 插入尾注     | Ctrl+Alt+D         |
| ⌥⌘G             | 转到         | Ctrl+G             |

其中两个在 Windows 上有所不同，原因与 Word 将它们分开的原因相同。**macOS 占用了 ⌥⌘D**——用于显示和隐藏 Dock——因此尾注在 Mac 上是 ⌥⌘E，在其他平台上是 Ctrl+Alt+D。而**转到**去掉了 Alt：Ctrl+G，Mac 上的组合键确实会用到它。

**Sheets**，在网格获得焦点时

| 快捷键（macOS） | 作用     | Windows / Linux |
| --------------- | -------- | --------------- |
| ⌥⌘0             | 外边框   | Ctrl+Shift+7    |
| ⌥⌘−             | 无边框   | Ctrl+Shift+−    |

Windows 并非 Mac 组合的改写。Mac 版 Excel 给 Sheets **两者**：⌘⇧7 和 ⌥⌘0 是同一外边框的两个按键，因此在 Windows 上该命令保留原有的 Ctrl+Shift 键位，Option 层级则不存在。

请注意，**⌥⌘0 在 Docs 中表示正文，在 Sheets 中表示外边框**。它们从不出现在同一编辑器中，因此实际不会冲突，但 ⌥⌘0 已被占用，不能用作全局快捷键。

**所有编辑器**：**⌥⌘R / Ctrl+F1** 折叠功能区，如上所述。

这样 ⌥⌘D 在 macOS 上就留给 GenOffice 使用，以备将来某个命令需要。
