# 快速开始：界面与基础

GenOffice 是一套完全在你本机运行的办公套件：一个窗口、一排标签页，内含六个编辑器——Docs（文字处理）、Sheets（电子表格）、Slides（演示文稿）、PDF、Markdown 和 HTML。文件是真正的 .docx / .xlsx / .pptx / .pdf 文件，可与 Word、Excel 和 PowerPoint 完全互换。无需网络连接。

## 界面概览

![主屏幕](img/home-screen.png)

窗口由三部分组成：

- **标签栏（顶部）**：每个打开的文件都是一个标签页。最左侧的 Home 标签页始终存在，无法关闭；其余标签页是你的文档。双击标签页可直接重命名文件。
- **内容区**：当前标签页对应的编辑器（或 Home）。
- **菜单栏**：macOS 上位于系统菜单栏，Windows/Linux 上位于窗口顶部。文件/编辑/视图菜单会随当前编辑器调整。

## 创建文档

以下任一方式：

- 点击 **Home** 中[快速开始](help://getting-started)区域的快速创建标签页（AI Docs、AI Sheets、AI Slides……）。
- **文件 ▸ 新建**菜单：Docs（⌘N/ctrl+N）、Sheets、Slides、Markdown、HTML 或 PDF。
- 将文件拖到窗口上，或在文件管理器中双击它（前提是 GenOffice 为默认应用）。

新文档以无标题方式打开；磁盘上的文件仅在首次保存时创建。

## 打开文件

- **文件 ▸ 打开…**菜单（⌘O/ctrl+O）打开系统选择器：.docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html。
- 点击 Home 中**最近**列表的任意条目。
- 在终端执行 `genoffice <file>` 也能打开文件。

## 保存模型

- **手动保存**：⌘S/ctrl+S，或文件 ▸ 保存 / 另存为…。首次保存时会要求你选择路径和名称。
- **自动保存**仅在你至少手动保存过一次文件后才启用——只是阅读过的 PDF 绝不会被暗中改写。内容变更后不久即触发自动保存。
- 若关闭有未保存修改的标签页，会先询问你选择保存 / 丢弃 / 取消。
- 每次写入都是原子的（临时文件 + 重命名），因此断电不会留下半个文件。

## 常用快捷键

| 操作             | macOS | Windows / Linux |
| ---------------- | ----- | --------------- |
| 新建文档         | ⌘N    | ctrl+N          |
| 打开             | ⌘O    | ctrl+O          |
| 保存             | ⌘S    | ctrl+S          |
| 关闭标签页       | ⌘W    | ctrl+W          |
| 打开本手册       | F1    | F1              |
| 折叠功能区       | ⌥⌘R   | Ctrl+F1         |

**折叠功能区**在每个编辑器中都可用。标签行保持原位，下方的命令带被隐藏；当前选中的标签页同时充当折叠控件，因此功能区折叠时没有标签页处于选中状态，按任意标签页即可恢复命令带。双击标签页效果相同。每个编辑器会记住其折叠状态。Docs 还增加了一档中间密度：**⌥⌘K** / Ctrl+Alt+K 将命令带压缩为仅图标，同样会被记住。

各编辑器内部的快捷键（格式刷、查找替换、表格操作……）见各自章节；Docs 还提供一个可搜索的全部键盘快捷键对话框（**⌘/**）（见其章节）。

## Option+Command 快捷键

Option+Command 是 Word 留给结构化跳转的层级，GenOffice 同样如此填充。Docs 占用了大部分，Sheets 为对齐 Excel 取用了其中两个；有一个快捷键处处通用。

**Docs**

| 快捷键（macOS）     | 用途             | Windows / Linux    |
| ------------------- | ---------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3     | 标题 1 / 2 / 3   | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0                 | 正文             | Ctrl+Alt+0         |
| ⌥⌘M                 | 段落             | Ctrl+Alt+M         |
| ⌥⌘A                 | 新建批注         | Ctrl+Alt+A         |
| ⌥⌘F                 | 插入脚注         | Ctrl+Alt+F         |
| ⌥⌘E                 | 插入尾注         | Ctrl+Alt+D         |
| ⌥⌘G                 | 定位             | Ctrl+G             |

其中两个在 Windows 上不同，原因与 Word 将它们分开相同。**macOS 占用了 ⌥⌘D**——显示和隐藏 Dock——因此尾注在 Mac 上是 ⌥⌘E，其他平台是 Ctrl+Alt+D。而**定位**去掉了 Alt 键：Ctrl+G，Mac 快捷键则保留它。

**Sheets**，当网格获得焦点时

| 快捷键（macOS） | 用途     | Windows / Linux |
| --------------- | -------- | --------------- |
| ⌥⌘0             | 外侧边框 | Ctrl+Shift+7    |
| ⌥⌘−             | 无边框   | Ctrl+Shift+−    |

Windows 并非 Mac 组合的重写。Mac 版 Excel 给 Sheets **两者**——⌘⇧7 和 ⌥⌘0 是同一外侧边框的两个按键——因此在 Windows 上该命令保留原有的 Ctrl+Shift 槽位，Option 层级则直接缺失。

注意：**⌥⌘0 在 Docs 中表示正文，在 Sheets 中表示外侧边框**。它们从不出现在同一编辑器中，因此使用中不会冲突，但 ⌥⌘0 已被占用，不能用作全局快捷键。

**每个编辑器**：**⌥⌘R / Ctrl+F1** 折叠功能区，如上所述。

这样 ⌥⌘D 在 macOS 上保持空闲，以备将来有命令需要。
