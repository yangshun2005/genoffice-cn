# 字体：系统字体与可下载字体家族

## 字体列表

字体控件位于每个编辑器的“主页”选项卡上（下图为 Slides 中的字体组）：

![Slides 功能区中的字体组](img/fonts.png)

每个编辑器的字体选择器汇集了：本地已安装的字体 + 平台常见候选字体（Windows 和 macOS 的常见家族，涵盖拉丁文和东亚文字，包括东亚字体在其原始系统上标注的本地化名称）。当系统能够枚举本地字体时，列表按实际存在的字体分组；否则回退到完整的候选列表。

## 可下载字体（Slides）

- Slides 的字体选择器打开一个**字体目录**：精选的 OFL 字体，覆盖多种书写系统；每个家族提供常规和粗体两种字重。
- 选择某个字体后，会从 CDN 下载并安装到应用的字体库中（通过校验和固定版本）——之后对所有文档可用，无需在系统层面安装。
- 安装内容存放在应用的私有目录中，随应用一同删除。

## 东亚排版

- Docs 中的东亚字体支持字符压缩和与 Word 对齐的断行规则（参见 Docs 章节）。
- 目录中的东亚家族涵盖简体中文、繁体中文、日文和韩文，包括衬线和无衬线。

## 管理本地字体

- “安装字体文件…”入口从磁盘加载 .ttf/.otf 文件到应用的字体库中。
- 字体库按家族归档；同一家族的多个字重可以共存。
