# 字体：系统字体和可下载字体家族

## 字体列表

字体控件位于每个编辑器的“开始”选项卡（下图为 Slides 中的字体组）：

![Slides 功能区上的字体组](img/fonts.png)

每个编辑器的字体选择器合并了：本地已安装字体 + 平台常见候选字体（常见的 Windows 和 macOS 字体家族，西方和 CJK，包括 CJK 字体在各自系统上报告的本地化名称）。如果系统能列出本地字体，列表将根据实际存在的字体分组；否则回退到完整候选列表。

## 可下载字体（Slides）

- Slides 的字体选择器打开一个**字体目录**：精心挑选的 OFL 字体集，涵盖多种文字；每个家族有常规和粗体两种字重。
- 选择后，该字体会从 CDN 下载并安装（带固定校验和）到应用的字体存储中——之后可用于任何文档，无需在系统级别安装。
- 安装内容存放在应用的私有目录中，随应用一起消失。

## CJK 排版

- Docs 中的 CJK 字体获得与 Word 对齐的文本压缩和禁则处理规则（参见 Docs 章节）。
- 目录中的 CJK 字体家族涵盖简体中文、繁体中文、日文和韩文，均有衬线和无衬线版本。

## 管理本地字体

- 安装本地字体文件的选项可将磁盘上的 .ttf/.otf 文件加载到应用的字体存储中。
- 存储按家族组织；同一家族的多个字重可以共存。
