# AI 助手面板

每个编辑器都可唤起 AI 面板：选中内容、输入指令，即可看到结果逐步呈现。

## 打开与使用

![Docs 中的 AI 面板](img/ai-panel.png)

- 入口：每个编辑器工具栏上的 **AI 按钮**、上下文菜单中的 **询问 AI**，或标记栏上的“询问 AI”。
- 用日常语言描述任务（改写这段 / 把这一列改成百分比 / 重新排版这一页……），按 Enter 发送。
- 回答**逐步**渲染；AI 需要工具时（读取文档、修改文档）会直接调用，直到完成。
- **停止**：随时中断当前步骤。
- **队列**：回答进行中时，按 Enter 会把消息加入队列而非丢弃——输入框上方的进度条会显示数量；展开后可编辑、删除、重排、暂停或清空。当前轮次结束后会自动发送下一条；Esc 仍会终止当前轮次。

## 能做什么

- **Docs**：改写/扩写/翻译/摘要，插入表格和图片，修改格式；每一步都会先创建状态快照。
- **Sheets**：公式、填充数据、批量转换、格式设置。
- **Slides**：生成整套演示文稿、调整版式、改写文本。
- **PDF**：针对选中文本或页面提问、回答和总结。
- **首页 ▸ Ask AI** 基于你标星的文档作答并引用来源——知识库面板在“首页”章节有独立小节，Docs 的 AI 面板也具备同样能力。

## 撤销与安全

- Docs 中的面板维护**版本列表**：每一步一个快照，可回退到任意版本，回退本身也能用 Ctrl+Z 撤销。快照在文档重新打开后依然保留。
- AI 的修改走与手动修改相同的编辑路径（可撤销、需保存）——不会绕过你的保存确认。

## 对 AI 隐藏选区

- 在 Slides、HTML 和 Markdown 中，可将选区对模型隐藏：右键 ▸ **对 AI 隐藏选区**，为占位文本命名，模型读取 `{{名称}}` 代替原文。（Markdown 通过工具栏上的划掉眼睛开关启用；HTML 的入口在源码面板中。）
- 文件保留真实文本——保存、导出和打印均不受影响，标记在重新打开后依然有效。同一菜单项可取消隐藏（Markdown 还提供 **重新向 AI 显示选区**）。
- HTML 隐藏元素内容、属性值和脚本中的字符串字面量；渲染后的页面始终不变。
- Slides 还能隐藏整张图片、视频和音频，含隐藏内容的幻灯片不会作为截图发送：自动版式检查会跳过该页并给出提示。
- 仅对应用内的 AI 生效——CLI、MCP 工具和无头导出直接读取文件，仍能看到文本。

## 隐私

- 指令和相关文档内容会发送到**你配置的模型服务**（云端 Genspark 或自定义端点，见下一章）；未配置则不发送任何内容。
- 本地文件不会发送到其他地方；BYOK 密钥保存在本机的应用设置文件中，仅在请求头中发送。
